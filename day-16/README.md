## 二、洞洞板（万能板）到底是什么

这是今天第一个必须搞清楚的认知 —— 它跟面包板**完全不是一回事**。

| | 面包板 | 洞洞板 |
|---|--------|--------|
| 孔内部 | 有**铜条**，一行 5 个孔内部相连 | **每个孔是独立焊盘**，彼此不连通 |
| 连不连 | 插进去就连通 | 不焊就不通，全靠**焊锡**连通 |
| 用途 | 临时搭电路，拔了就没 | 永久电路，焊死不会掉 |

**所以洞洞板上"串联"不需要跳线** —— 把两个元件的引脚**塞进同一个孔**，焊锡一包，它们就是同一个电气节点。

规格：5×7cm 双面喷锡，标准孔距 **2.54mm**（0.1 英寸）。

## 三、共用孔串联法（今天的核心手法）

### 电阻选型

选了 **5 个不同阻值**，从左到右：

```
R1 = 330Ω     R2 = 1kΩ     R3 = 2kΩ     R4 = 1kΩ     R5 = 220Ω
```

**为什么用不同阻值？** 这是刻意的 —— 见 §五 的"累计值唯一"原理。如果 5 个都是 1kΩ，测出 3kΩ 你只知道"通了 3 个"，不知道断在哪；用不同阻值，测出哪个数就知道链子通到哪一节。

每个阻值只用 1 个（电阻每种 10 个，不必省，但也没必要浪费）。

### 孔位排布

```
  孔1    孔3    孔5    孔7    孔9    孔11
   ●──────●──────●──────●──────●──────●
   │  R1  │  R2  │  R3  │  R4  │  R5  │
   └──────┴──────┴──────┴──────┴──────┘
  头                （共用孔）              尾
```

| 电阻 | 两端孔位 |
|------|---------|
| R1 330Ω | 孔 1 ↔ 孔 3 |
| R2 1kΩ | 孔 3 ↔ 孔 5 |
| R3 2kΩ | 孔 5 ↔ 孔 7 |
| R4 1kΩ | 孔 7 ↔ 孔 9 |
| R5 220Ω | 孔 9 ↔ 孔 11 |

**孔 3 / 5 / 7 / 9 各塞两根引脚** —— 这就是节点，焊锡包住两根引脚 = 连通，不需要任何跳线。

## 四、安装手法：架空式弯脚（在离本体 3mm 处折）

### 从哪一面插、在哪一面焊

**从正面（元件面）插入，在背面焊接。** 这是通孔焊接的标准做法：元件本体在正面，引脚穿过孔，在背面把引脚焊到焊盘上。

### 引脚太长怎么办

电阻引脚出厂很长，直接穿到底会从背面伸出一截，剪掉又浪费。实际用的是**架空式弯脚**：

```
            本体（架空在板面上方，不贴板）
        ┌─────────┐
        │         │
    ────┘         └───     ← 在离本体 3mm 处弯 90°
        ↑         ↑
       3mm       3mm
    ├──── 跨度 ≈ 本体长 + 6mm ≈ 12.5mm ≈ 5 个孔距 ────┤
```

1. 在离本体 **3mm** 处把两脚各弯 90°（**不是**贴着本体折）
2. 两脚弯的位置要一致，跨度自然变成 **本体长度 + 6mm ≈ 12.5mm ≈ 5 个孔间距**
3. 从正面插入：因为弯点离本体有 3mm，**两头穿过的孔间隔会非常大**，本体是**架空**在板面上方的，不贴板
4. 背面刚好露出 **3mm**，正好够焊，**不浪费引脚线，也几乎不用剪断**

> ❌ 说明书上常见的另一种是"贴板卧式 ∏ 形"：离本体 1~2mm 弯、跨 2 个孔距（5.08mm）、本体平躺贴住板面。那样本体压在板上，背面伸出 3~5mm 还得剪。**本次练习没用它**，架空式更省料、更少一道剪脚工序。

### "八字"固定法（翻面不掉的关键）

翻面焊接时元件会掉出来。解法：**背面把两根引脚向外各掰 30~45°**，像"八字"叉开，元件就被卡住了，板子平放在桌上稳稳的。

架空式下两脚本来就向两侧外张，配合轻轻掰一下就够了。

### ⚠️ 关于"插入深度"的一个易错点

这里我一开始想岔了，值得记下来：

> **"少插一点、只露 5mm" 和 "插到底之后露 5mm" 是两回事。**

- ✅ **插到底之后露出 3mm**：引脚弯折处紧贴板面，焊得住，焊点有机械强度
- ❌ **少插 3mm**：引脚根部悬在孔中间，本体浮在板面上方十几毫米，立不住，翻面就歪

**插入深度由"弯脚位置"决定，不是由用力大小决定。** 想控制背面露出多少，就改弯脚的位置（离本体几毫米 = 背面露出几毫米），别靠"插得轻一点"。

**既然是练手，本次引脚一根都没剪** —— 留着长脚，回头用吸锡器全拆下来，电阻还能接着用（顺带完成 §八 的拆焊练习）。

## 五、万用表验证：分段求和自检法 ⭐

这是今天最有价值的一条方法论。

### 理论值

```
全链 = 330 + 1000 + 2000 + 1000 + 220 = 4550Ω = 4.55kΩ
```

电阻公差 ±5%，实测在 4.3~4.8kΩ 都算正常。

### 实测结果（2026-09-18）

| 测哪 | 理论值 | 你的实测 | 判定 |
|------|--------|---------|------|
| **全链**（头 ↔ 尾） | 4.55kΩ | **4.5kΩ** | ✅ |
| **前三个焊点**（R1+R2） | 330+1000 = 1.33kΩ | **1.3kΩ** | ✅ |
| **后四个焊点**（R3+R4+R5） | 2000+1000+220 = 3.22kΩ | **3.2kΩ** | ✅ |

三个数全对。

### ⭐ 关键：为什么"两个分段之和 = 全链"能证明没虚焊

```
前段 1.33k  +  后段 3.22k  =  4.55k  =  全链
实测 1.3k   +  3.2k        =  4.5k   =  实测全链 4.5k  ✅
```

**两段正好把整条链无重叠、无缺口地分完。** 这意味着分段点（孔 3，R1 与 R2 的共用孔）**真的导通了**。

如果孔 3 虚焊会怎样？

- 测"前三个焊点"时，电流走不通 R1→R2，测出来是 **无穷大 / OL**，而不是 1.3k
- 测"后四个焊点"时，你会得到 R3+R4+R5 没错，但**全链也会是无穷大**

也就是说：**光测"全链 4.5k"只能证明链子整体没断；再加上"分段之和 = 全链"，才能证明中间节点也是通的。** 这比拿导通档"滴"一声强得多 —— 蜂鸣只能告诉你"通"，电阻值能告诉你"通的是哪一段"。

> 📌 这是 Day 15 那条通用方法论（*"任何通断测试都要先问'会不会本来就通？'"*）的升级版：**别只测一个总数，切成几段分别测，让它们互为验证。** Day 21 整车接线排查会继续用。

### 一个措辞上的歧义（记下来免得以后自己绕晕）

"前三个焊点"这个说法有两种理解：

- 指**前三个焊盘**（孔1-孔3，跨 2 个电阻）→ 1.33kΩ ✅ 与你测的 1.3k 吻合
- 指**前三个电阻**（R1+R2+R3 = 3.33kΩ）→ 那 1.3k 就不对

从数字看显然是前者。以后记录统一写成 **"R1+R2"** 这种形式，不写"前三个"。

## 六、短路测试（标准 ②）✅ 已完成

**实测日期**：2026-09-18｜**档位**：2MΩ｜**结果**：**焊点 ↔ 旁边空孔 = OL** → 无短路 ✅

**怎么测**：万用表打到 **2MΩ 档**，两表笔点**相邻两个焊盘**：

| 测哪 | 应该 | 实测 |
|------|------|------|
| 孔 1 ↔ 孔 3（R1 两端） | 约 **330Ω**（链上，应有读数） | — |
| 孔 3 ↔ 孔 5（R2 两端） | 约 **1kΩ**（链上，应有读数） | — |
| **链子 ↔ 链子旁边空着的孔** | **OL / >1MΩ** | **OL** ✅ |
| **4 个共用孔（3/5/7/9）各自与相邻的空孔** | **OL / >1MΩ** ← 重点 | **OL** ✅ |

**重点在 4 个共用孔**：那里一个孔塞了两根引脚又加了一坨锡，是最容易锡漫到隔壁焊盘的位置。逐个量它与四周空孔的电阻，都应该 >1MΩ。

### OL 在这个位置代表什么

**OL = Over Load（超量程/开路）**，万用表在电阻档推不出电流，说明两点间电阻超出该档量程 = **没有锡桥、不通**。标准是 >1MΩ，2MΩ 档显示 OL 意味着 >2MΩ，**远超标准** ✅

### ⚠️ 同一个 OL，在链上和链外含义相反

| 你测的是哪两点 | 应该显示 | OL 的含义 |
|---|---|---|
| **链外**（焊点 ↔ 旁边空孔、同一列上下不相关的孔） | **OL** | ✅ 正常，无短路 |
| **链上**（同一电阻两端、共用孔里的两根引脚） | 330Ω / 1kΩ / 2kΩ 或约 0Ω | ❌ **虚焊开路了** |

所以：测"孔 1 ↔ 孔 3"这种**链上**相邻孔时显示 OL 反而是坏消息——中间串着 R1，本该显示 330Ω 左右。本次测的是链外空孔，OL 正是要的结果。

### 测之前先排除表本身的问题

1. 两表笔**悬空不碰** → 显示 `1` 或 `OL` ✅
2. 两表笔**金属尖短接** → 显示 `0.2~0.5Ω`（表笔线阻），蜂鸣档会响 ✅
3. 表笔插孔：黑插 `COM`，红插 `VΩmA`（**不是 10A/20A 孔** —— 插错会一直 OL）

### 两个容易误判的点

- **测绝缘时手别同时捏住两根表笔的金属部分**：人体电阻（几百 kΩ 到几 MΩ）会和被测点并联，把 OL 拉到 1.x MΩ，看着像"勉强及格"其实是你的手。捏绝缘柄即可。
- 用 **2MΩ 档**测绝缘就够：这档显示 OL 即 >2MΩ，已满足 >1MΩ 要求，比 200MΩ 档读数稳定得多。

### 如果量出几百 Ω 或几 kΩ

→ 有锡桥或助焊剂残留导电：烙铁头擦干净，压在两焊盘之间把多余的锡"粘"走，再量一次。

## 七、焊点质量评判（看 [`五个电阻串联背面焊接点.png`](./五个电阻串联背面焊接点.png)）

### ✅ 合格的部分

| 项目 | 结论 |
|------|------|
| 导通 | ✅ 见 §五，全链 4.5kΩ 且分段自洽 |
| 锡是否上了焊盘 | ✅ 每个焊点都盖住了孔和引脚 |
| 锡桥 | ✅ §六 已用表确认：焊点 ↔ 相邻空孔 = OL（>2MΩ），无短路 |
| 冷焊 | ✅ 未见明显灰暗/龟裂/豆腐渣状 |
| 引脚未剪 | ✅ 符合"练手不剪、回头全拆回收"的决定 |

### ⚠️ 要改的两点

**① 锡量偏少**

大片焊盘**外圈的铜色还露在外面**，锡只盖住中间一小块。Day 15 定的标准是"锡铺满整个焊盘、边缘收在焊盘内"—— 现在是"连铺满都没做到"。

后果：机械强度不足，小车震动时可能出问题。电气上现在通，但不可靠。

**② 焊点形状偏拉长，不是小丘**

锡顺着引脚**往上爬了一截**，形成"沿腿爬的柱"，而不是"引脚从小丘顶冒出来"。

成因：
- 送锡时**锡丝贴着引脚**（应该贴焊盘与引脚的**交界处**，让锡被焊盘吸进去）
- **加热时间偏长**，引脚上部也热了，锡就顺着热的地方往上爬

### 补锡怎么补（可选，练手板可以就留着当参照）

```
① 烙铁头同时压住【焊盘】和【引脚根部】（不是引脚中段）
        ↓
② 锡丝从【对面】送，碰到交界处
        ↓
③ 看到锡自己摊满整个焊盘 → 先撤锡丝
        ↓
④ 再撤烙铁，别动 1~2 秒
```

补完应该看到：焊盘**整个被锡覆盖**，但锡的边缘还收在焊盘内，中间是一个矮矮的小丘，引脚从丘顶冒出。

## 八、拆焊练习（吸锡器）—— 实战：拆开发板上的原厂焊锡

《逐日指南》第 4 项。在 ESP32-S3 开发板上实战完成。

**实拍**：[`电烙铁和吸锡器拆焊_正面.png`](./电烙铁和吸锡器拆焊_正面.png)（正面）、[`电烙铁和吸锡器拆焊_背面.png`](./电烙铁和吸锡器拆焊_背面.png)（背面焊点面，板号 `10696356A_Y4_250714`）

### 核心手法：一手烙铁、一手吸锡器

对，**就是一手用烙铁把锡熔化、另一手用吸锡器把它吸走**。但有一个动作必须提前做，否则你缺第三只手：

> **吸锡器要在加热【之前】就把活塞压下去**（听到"咔"锁定）。
> 等到锡熔化再按，按下活塞的力会让你手抖、喷嘴偏移，而且一秒钟内锡就凝固了。

### 步骤

```
① 吸锡器【先压下活塞】锁定（提前准备好）
        ↓
② 烙铁压住焊点，等锡【完全熔化】成亮亮的圆球（约 1~2 秒）
        ↓
③ 喷嘴垂直贴住孔口/熔锡，同时【按释放钮】—— "啪"一声，锡被吸走
        ↓
④ 烙铁撤开；孔还堵就重复 ②~③，或先【加一点新锡】再吸
        ↓
⑤ 引脚松动后【趁热用镊子夹住拔出】，别硬拽
```

**第 ④ 步为什么要"加新锡"**：老锡里助焊剂早烧光了，流动性差、熔点高，吸不动。加一点新锡丝进去，既补了助焊剂又改善导热，反而更好吸。这是新手最容易想不通的一点——**拆焊反而要加锡**。

### 三个常见失败原因

| 现象 | 原因 | 解法 |
|------|------|------|
| 吸不动、锡还在 | 活塞没提前压 / 锡已经凝固了 | 先压活塞再加热；动作一气呵成 |
| "啪"了但没吸到锡 | 喷嘴**隔着一段距离**，吸的是空气 | 喷嘴要贴住熔锡，形成密封；**烙铁别挡住喷嘴**，从侧面压焊盘加热，喷嘴从正面贴孔 |
| 锡吸走了但引脚拔不出 | 孔里残留一点锡把引脚粘住 | 再加新锡重吸一次；或趁热点住焊点，用镊子**轻轻转动**引脚试探，松动了再拔 |

⚠️ **别硬拽**：焊盘和铜箔是粘在板上的，硬拽会把焊盘整个撕下来，洞洞板那个孔就废了。

### 用完要清理

吸锡器吸进来的锡**趁热排出去**（对着废料筒多按几次活塞，或拆开喷嘴捅一下）。锡凝在腔体里会把活塞卡死，下次就压不下去了。

### 什么时候会用到它

真实场景随时会出现：改错孔位、回收元件、Day 21 整车接线返工。这次是在 ESP32-S3 开发板上练的手，洞洞板上那 5 个电阻留着当 Day 16 的成品记录。

> 📌 **吸锡器的局限**：单孔直插（电阻、排针）它很好用；密集脚位（Day 21 那种排母、贴片）更适合**吸锡带（编织铜带）**—— 烙铁压在带上，锡被毛细作用吸进编织缝隙。现阶段只有吸锡器，够用。

## 十、出了什么问题 & 怎么修

| 症状 | 原因 | 修复 |
|------|------|------|
| 翻面时元件掉出来 | 引脚没掰开 | 背面两脚向外掰 30~45° 成"八字" |
| 元件本体悬空十几毫米 | **"少插"了**，不是"插到底露 5mm" | 插入深度由**弯脚位置**决定，改弯脚位置，别靠少插 |
| 全链测出无穷大 | 链子中间某个共用孔虚焊 | 逐个孔补锡；用分段测量定位是哪一节 |
| 分段之和 ≠ 全链 | 分段点（共用孔）虚焊，或测的时候表笔碰错了孔 | 重测一次；仍不等就是那个孔有问题 |
| 焊点锡量偏少、铜色露在外面 | 送锡时间太短，或撤锡太早 | 补锡：烙铁压焊盘+引脚根部，锡从对面送，看到摊满焊盘再撤 |
| 锡沿引脚往上爬成"柱" | 锡丝贴着引脚送 + 加热时间偏长 | 锡丝送到**焊盘与引脚交界处**；加热 2~3 秒够了，别磨 |
| 相邻焊盘连通 | 锡太多 | 烙铁头擦净，压在桥上把多余锡粘走 |

## 十一、与《逐日指南》的出入

| 指南原文 | 本 README | 理由 |
|---------|-----------|------|
| 5 个电阻串到洞洞板 | ✅ 沿用（330/1k/2k/1k/220） | 改成**不同阻值**，让累计值唯一，方便定位断点 |
| 检查：无虚焊 / 无短路 / 焊点平整 | 沿用，① 已过 ② 已过 ③ 有瑕疵 | — |
| ESP32-S3 排针 → 转接板（44 引脚） | ⏭️ **跳过** | 开发板出厂已焊好排针，再焊一遍无意义；且 44 脚密集焊接失败风险高，一旦桥连会毁掉主控 |
| USB Type-C → 自制电源板 | ⏭️ **跳过** | 未采购 USB Type-C 座，属扩展项；现阶段用开发板自带 USB 供电即可 |
| 拆焊练习：拆下一个引脚再焊回 | ✅ 已实战 | 拿 ESP32-S3 开发板练的手；洞洞板上 5 个电阻留作成品记录，不拆 |
| 输出：焊接完成品照片 + 万用表测试结果 | ✅ 已有照片，测试结果记录在本 README §五 | — |

> 原则：**能省的元件就省。** 跳过的两项都不影响 Day 17–21 的超声波 / IMU / 电机接线，等真正需要自制转接板时再做不迟。
