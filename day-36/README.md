# Day 36 — P 控制

> 硬件：Day 35 的五路 AO + 五路 DO + TB6612 一根不动
> 核心：把"线在哪"变成连续的转向量——`turn = Kp × pos`，本项目的第一个闭环
> 固件：[`实验1-P控制.ino`](./实验1-P控制/实验1-P控制.ino)

## 一、Day 35 留下了两个毛病

开环三档跑通了，但日志里两件事明摆着：

| 毛病 | 数据 | 为什么改不掉 |
|---|---|---|
| 到线附近来回摆 | 0.49 次/秒（约 2 秒一周），摆幅 `pos` ±800 | 修正量只有两档：偏一点就整档切过去，切过去就过头，过头再整档切回来 |
| 甩不掉的静差 | `pos` 常驻 +400（510 帧），线稳定偏右 15mm | 车有个持续的右偏扰动，要靠舵量抵消，而舵量来自偏差本身——稳态必须留一个偏差 |

这两个毛病是同一个根：**修正量不随偏差大小变**。偏差 10 码和偏差 800 码，修正量一模一样。
所以今天换控制律：

```
turn = Kp × pos × steerSign      （steerSign = −1，阵列镜像，见 Day 35）
左轮 = 巡航 + turn        右轮 = 巡航 − turn
```

偏差小 → 修得轻；偏差大 → 修得重；偏差为 0 → 不修。这就是"比例"两个字的意思。

## 二、前进量和转向量要分开

这是今天最容易写错的一处，指南特意点了。

Day 35 的三档是"内轮一减速，整车的速度基准也跟着掉"：`L75 R115`，平均 duty 95；
`L115 R115`，平均 duty 115。**误差一出现，车就变慢了。**这看着没什么，但它把两件事
耦在了一起：转向和车速。调 Kp 的时候你分不清"车反应变好了"是转向修得准，还是
"车慢了所以显得稳"。

今天拆开：

```
转向量：turn = Kp × pos × steerSign   ← 只决定"往哪修、修多猛"
前进量：cruise = 115（常量）      ← 不随误差变化
左轮 = cruise + turn    右轮 = cruise − turn
```

`pos > 0` 是黑心压在 3/4 号一侧、也就是**车的左侧**（阵列镜像：`W[]` 假设"0 号最左"，
装车时 0/1 号实际在车的右侧，Day 35 台架实测）→ `turn < 0` → 左轮慢 → 车往左去够线。
这条符号链 Day 35 已经验过，`steerSign = −1` 就是为它存在的；**当前值被按反了的话，
同一个 `pos` 会给出相反的弧线，先按 `s` 修回来再调 Kp**。

误差为 0 时两轮都是 115，和误差 ±400 时的**平均 duty 一样**。差别只在两轮的差。
指南那句"前进量不能随误差消失而停"就是这个意思——反过来说：误差大时车也不能加速。

`turn` 限幅在 ±巡航 duty 内，**内轮最低到 0，不反转**。这台车是差速转向，两个轮子
都朝前，转弯靠转速差（Day 35 架起来时看到的就是这个）。内轮停转等于"外轮单独驱动"，
转向能力到顶；再想更强只能提高巡航 duty 或降低 Kp。日志里会打一行
`← turn 限幅：内轮停转`——直道上频繁出现这一行，说明 Kp 太大或巡航太小。

## 三、Kp 的五档

`Kp` 不是连续调的，先跳五个预设档试出现象，再微调。串口按 `1`~`5` 直接跳，
`k` / `j` 按 0.001 微调。

`pos` 的量纲是 ±1000（Day 33 定：居中 0、压最边一路约 ±900），所以：

| 档 | `Kp` | `pos=±800` 时的 turn | 预期现象 |
|---|---|---|---|
| 1 | 0.005 | ±4 | 几乎修不动，车会一直偏出去 |
| 2 | 0.015 | ±12 | 修得慢，弯道跟不上 |
| 3 | 0.030 | ±24 | 中间档，通常最接近工作点 |
| 4 | 0.060 | ±48 | 修得急，直道可能开始摆 |
| 5 | 0.120 | ±96 | 内轮频繁停转，明显来回摆 |

第 3 档是默认值，因为它对应的左右轮 duty 差是 48/255 ≈ 19%，和 Day 35 的
`115−75 = 40` 同一个数量级——Day 35 已经能跟住 18 秒，说明这个量级的方向修正
是够的，问题是它不随偏差变。

**档 4 / 5 是干什么的**：故意试"修太多"长什么样，不是让你从里面挑。1/2 档修不动、
4/5 档来回摆，工作点在中间——3 档还摆就退到 2 档附近微调，3 档还修不动就进
4 档附近微调。5 档会打出 `← turn 限幅：内轮停转`，那是内轮已经降到 0、
靠外轮单独拖着转，转向能力到顶。

**日志最后一段怎么读**：

```
[0 0 1 0 0] n=1 | raw  703  651 1687  252  291 | pos -175 turn  +24 L139 R 91 右弧线
                                                     ─┬─  ─┬─  ─┬─ ─┬─ ─┬─
                                                   偏差  转向量 左轮 右轮 动作
```

看 `L` 和 `R` 谁小：**`L` 小 = 左轮慢 = 左弧线**，**`R` 小 = 右轮慢 = 右弧线**，
两个一样 = 直行。架起来时轮子只差几十码，肉眼看不出来，看数就行。

**工作点怎么认**：能跟上但不摆。三个可判的标志：

- 直道上 `pos` 大部分时间落在死区 ±150 内（日志里 `L115 R115` 且 `turn 0` 的帧占比高）
- 不出现连续的 `← turn 限幅`
- 刹停次数明显少于 Day 35 的 29 次

## 五、串口命令

| 键 | 作用 |
|---|---|
| `c` / `b` / `w` / `t` | 标定白底 / 黑底 / 总表 / 量电位器阈值（Day 34 原样） |
| `p` | 曲线模式：每行 `pos / 压线路数×250 / turn`，喂 Python 画图 |
| `q` | 静音：关掉每帧 raw 日志 |
| `s` | 转向方向取反 |
| **`1` ~ `5`** | **跳到第 N 档 Kp** |
| **`k` / `j`** | **Kp 微调 ±0.001** |
| `+` / `-` | 巡航 duty ±5 |
| `[` / `]` | 死区 ±25 |

**NVS 命名空间延用 Day 35 的 `day35`。**同一台车、同一套装车高度，标定表就是同一份，
烧完直接读昨天那份，**不用重按 `c`/`b`/`t`**。多存了一个 `kp` 键，Day 35 的固件
没有它，读不到就用默认第 3 档，不影响别的。

⚠️ 但**换环境 / 改光照 / 动过高度 → 白底会漂，必须重按 `c`/`b`**。昨天那份表是在
"打印黑 + 空白 A4"上标的，今天还是这两张纸、同一个装车高度，就不用重标。
上电看到 `[nvs] 已恢复上次的标定 + 方向 + Kp` 就是读到了。

## 六、上机步骤

1. **先确认标定读到了**。烧完上电，串口应打 `[nvs] 已恢复上次的标定 + 方向 + Kp`，
   按 `w` 扫一眼五路量程还是昨天的数（722~1967）就行，不用重标。
2. **架起来验方向**（Day 35 那套，一分钟）。黑道具遮 2 号 → 遮 1 号 + 2 号 →
   遮 3 号 + 4 号，看每帧日志最后那段。**别按 `q`**——`q` 一静音，
   `turn`/`L`/`R`/`左弧线`/`右弧线` 全没了，只剩状态变化，什么都验不了。
3. **五档各录一段**。同一段直道，`1` → 录 20 秒 → 直接按 `2` → 录 → ……
   **中间不用按 `q`**。嫌滚屏快就按 `p`（曲线模式，每行只有
   `pos / 压线路数×250 / turn` 三个数）。
   每段都要包含：直道中段（看跟不跟得住）+ 一次故意把车摆出去再放回（看修不修得回来）。
   边跑边在纸上记现象，别等日志——现象是"看起来怎样"，日志只给数。
4. **在工作点附近微调**。`k` / `j` 按 0.001 走，找到能跟上但不摆的那一档。
5. **换速度再验一次**。`+` 把巡航 duty 提到 130，同一条赛道再跑。
   **Kp 和速度不是独立的**：快了同样的偏差对应更大的位移，同样的 Kp 会显得更"猛"。
   两个速度都记下工作点，Day 38 拍对比视频要用。

**五档是横向比，不是测绝对值。**只要五段用同一个电源、同一条赛道、同一段路，
比出来的"哪一档不摆"就有效——不需要电源"够好"，只需要"五段一样"。
电源差只影响"这个 Kp 换块电池还成不成立"，那是 Day 38 之后的事。

赛道不用打印：白 A4 + 黑胶带贴一条 10mm 粗的直线就行，黑笔描一条也行。
要打印就用 Day 35 那两张：[`../day-35/巡线轨迹-A4.svg`](../day-35/巡线轨迹-A4.svg)
和 [`../day-35/黑底标定-A4.svg`](../day-35/黑底标定-A4.svg)。

## 七、上机结果

### 架起五档测试：档位梯度对，方向反了

（2026-10-22，架起 + USB 供电 + 黑道具静态压住 1/2/3/4 四路、0 号留白，串口 `p` 曲线模式，日志 [`5档测试.txt`](./5档测试.txt)）

五段里 `pos` 都稳定在 +350~+401（均值 365），只按 `1`~`5` 换档：

| 档 | `Kp` | `Kp×365` 理论 | 实测 turn（均值/最大） | 右轮 duty | 限幅 |
|---|---|---|---|---|---|
| 1 | 0.005 | 1.8 | 1 / 1 | 114 | 无 |
| 2 | 0.015 | 5.5 | 5 / 5 | 110 | 无 |
| 3 | 0.030 | 11 | 10 / 11 | 105 | 无 |
| 4 | 0.060 | 22 | 22 / 24 | 93 | 无 |
| 5 | 0.120 | 44 | 41 / 46 | 74 / 69 | 无 |

实测和理论逐档吻合，五档全在线性区、**没有一档触到限幅**——duty 量程够用，"哪一档不摆"只能由地面跑的摆振决定，架起测不了。第 5 档右轮 74（最差 69）已低于 Day 21 量到的 6V 堵转点 75，这就是目视"右轮几乎不转"的由来，属预期现象。

**但方向是反的。** 日志全程 `pos = +365`，即黑心压在 3/4 号一侧 = 车的**左**侧，固件却在给右轮减速（`steerSign = +1`）→ 车往右、背离线。串口按一次 `s` 置 `steerSign = −1` 修掉，固件默认值也已改成 −1。修正后同一条日志的 `turn` 符号整个翻面：第 5 档变成左轮 74、右轮 115、左弧线。

日志末尾 `[state] 跟线 → 丢线（五路全黑）` 是黑道具最后把五路一起盖住，不是控制问题。

两个附带发现：

- **这次遮的不是 0 号。** 全程 `onCount = 4`（`压线路数×250 = 1000`）配 `pos = +365`，只能是 1/2/3/4 黑、**0 号是白的**。要模拟"线跑到 0 号那侧"（车的右侧），得把黑道具压到 0 号上、底下垫白，那时 `pos ≈ −750`、`n = 1`。
- **上电 `Kp ≈ 0.003`**，不是第 3 档的 0.030。NVS 里 `kp` 键读回的值和档位对不上，跑前先按 `1` 再按 `3` 强制跳回标准档。

## 八、还欠的

- ⏳ **工作点没定**。架起只能给出 turn 量（1/5/10/22/41，五档全在线性区、无限幅），"跟得住 / 摆不摆 / 刹停次数"三项必须地面跑。方向已按 `s` 修成 −1，日志 §七 那些 turn 符号要整个翻面再看。
- ⏳ **电池盒带不动车**。Day 35 架起来那次只能 USB 供电，地上跑是残存动力挪完的。
  P 控制对 duty 响应最敏感——动力不足时 duty 和转速的关系是畸的，`Kp` 会调到一个
  假工作点。先换电池 / 查电机堵转 / 量实际工作电压。
- ⏳ **白底漂移**。Day 35 台架不动都在漂：线正压 2 号时 `pos` 已经有 −169 的偏置
  （不漂的话是 +143，312 码摆幅，死区 150 的两倍）。P 项会把这个偏置当成误差去修，
  等于白送一个固定转向量。每次跑前重按 `c` 再按 `b`。
- ⏳ **路4 饱和**。AO 能读到 3951（黑底 921），`n[4]` 过 1 还涨，`W[4]=2` 再放大两倍。
  这一路会输出远大于 1 的假权重，把质心拽走——P 控制下等于一个不定量的固定扰动。
  先单测路4 高度和遮挡。
- 📌 500ms 丢线超时还是推理值。P 控制修正更快，同一段丢线在 P 下可能"自己就回来了"，
  这个超时值要不要跟着改，跑完看数据。
- ⏭️ **D 项（Day 37）**：`d = Kd × (pos − pos_prev) / dt`。今天只上 P，摆振靠调小
  `Kp` 压；Day 37 用 D 项专门治摆。
