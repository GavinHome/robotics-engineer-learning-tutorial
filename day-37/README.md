# Day 37 — 加入 D 项

> 硬件：Day 36 的五路 AO + 五路 DO + TB6612 一根不动
> 核心：`turn = Kp × pos + Kd × (pos − pos_prev) / dt`，用变化率治摆振
> 固件：[`实验2-PD控制.ino`](./实验2-PD控制/实验2-PD控制.ino)

## 一、Day 36 留下一个治不了的毛病

架起五档实测（[Day 36 §七](../day-36/README.md)）证明 P 这条路本身是通的：五档全在线性区、没有一档触到限幅，量程够用。但 P 有个**结构性**的治不了，不是调 Kp 能解决的：

**P 只看当前偏差，不看偏差在怎么变。**

车往线冲的时候，偏差正在飞快缩小，可 P 还是按"当前偏差"给那么大的修正量——于是冲过去；冲过去偏差反向变大，P 又给一大坨，于是摆回来。Day 35 那个 2 秒一周、摆幅 ±800 的摆动，根子就在这。

| 毛病 | P 能不能治 | 怎么治 |
|---|---|---|
| 静差（偏差恒定不变） | ✅ 能 | Kp 够大就能把偏差压进死区 |
| 摆振（偏差在来回变） | ❌ 治不了 | 只能调小 Kp 让它摆得轻——代价是修正也跟着变慢 |

所以今天加第二项，让它看**变化率**：

```
turn = Kp × pos + Kd × (pos − pos_prev) / dt
       ────────   ─────────────────────────
       纠偏          阻尼
```

## 二、D 项：只对变化率起作用

第二项的全部性格一句话：**偏差不动，它永远是 0**，和 Kd 多大无关。

这是今天最该先记住的，因为它决定了 D 项能治什么、不能治什么：

| `pos` 在干什么 | `Δpos` | D 项 |
|---|---|---|
| 静止偏在一侧（黑道具压住不动） | 0 | 0 |
| 正在往 0 靠近（车在够线） | 负 | 一个把 P 抵掉一部分的量 |
| 正在远离 0（车冲过头了） | 正 | 一个叠加到 P 上、把趋势按住的反向量 |

### 量纲推一遍（今天最容易配错的地方）

`d = Kd × Δpos / dt`。本固件控制周期固定 100ms，所以：

```
d = Kd × Δpos / 0.1 = Kd × Δpos × 10
```

拿 Day 35 实测的摆动当参照：2 秒一周、摆幅 ±800。1/4 周期 500ms 里走完 800，摊到 100ms 一帧：

```
Δpos ≈ 800 / 5 = 160 码/帧
Kd = 0.010 → d = 0.010 × 160 × 10 = 16
对照 P：Kp = 0.030、pos = 800 → turn = 24
```

→ **Kd 的工作区间在 0.005 ~ 0.020**，和 P 项同量级。超出这个区间就不是在阻尼，是在放大噪声（见 §四）。

### 为什么 D 也乘 steerSign

不需要给 D 单开一个方向常数，因为它要的正是"反对当前的变化"：

| 情况 | `Δpos` | `kd × Δpos × steerSign` | 效果 |
|---|---|---|---|
| 车往左够线，`pos` 从大正往 0 | 负 | 正 | 把 P 那个"按当前偏差算的大修正"抵掉一部分 → 不冲过头 |
| 冲过头，`pos` 从 0 往大正 | 正 | 负 | 叠加到 P 上让左轮更慢 → 把往右的趋势按住 |

两种情况都是"让 `turn` 的变化慢下来"，这就是阻尼。固件里两项共用同一个 `steerSign`，按 `s` 取反时一起翻，不会出现"P 对 D 反"。

### steerSign 的正负由线的黑白决定，不是固定值

这是今天实测踩出来的坑，比 D 项本身更值得记：`pos` 是**暗度质心**，所以"线在哪一侧"和 `pos` 符号的关系由线的极性决定。

| 测法 | 线压 3/4 号（车的左侧）时的 `pos` | 需要的 `turn` | 对的 `steerSign` |
|---|---|---|---|
| 黑道具压白底（Day 35 的测法） | 正（暗度集中在 3/4） | 负（左弧线） | **−1** |
| 白卡压黑底（Day 37 的测法） | 负（暗度集中在 0/1/2） | 负（左弧线） | **+1** |

同一套固件、同一个 `s` 键，换个线的极性就要反过来。所以**别背符号，每次拿道具验一遍**：

- 道具压住 0/1 号 → 日志应该 `R < L`、右弧线
- 压住 3/4 号 → 日志应该 `L < R`、左弧线
- 反了就按 `s`，写进 flash，不用重烧

flash 里现在存的是 `+1`，对应"白卡压黑底"这一套。将来贴黑赛道在白底上跑，上线前必须先按一次 `s`。

### 两个实现上的坑

- **死区只管 P，不管 D**。D 管的是"别冲过去"，而"冲过去"这件事正发生在死区里——在死区关掉 D，车照样冲过死区再摆回来。
- **`dt` 用真实帧间隔**，不是写死的 0.1。帧间隔超过 300ms（刚上电、刚静音回来、刚跑完 `n` 测量）就不算变化率，先把 `posPrev` 对齐到当前值。否则一个几百毫秒的大 `Δpos` 会让 D 无缘无故炸一下。
- **丢线期间 `posPrev` 跟着对齐**。丢线时 `pos` 不更新，线回来那一帧 `Δpos` 应该是 0 而不是"从丢线前跳到现在"。

## 三、D 单独试：只要 D、不要 P

串口按 `o`，`Kp` 临时归零只留 D（再按一次 `o` 恢复刚才那档）。指南让做这个实验，结论先说：**车巡不了线。**

原因：D 是阻尼不是纠偏。它只能让一个**已经存在的**运动慢下来，没法产生一个指向线的运动。偏出去之后没有任何东西把车推回来，它会越偏越远。

但这个实验在架起上特别清楚，值得做：

| 操作 | 应该看到 |
|---|---|
| 道具静止压住一侧，按 `o` | `turn` 恒 0，两轮都是巡航 duty，车直行（然后慢慢飘走） |
| 手把道具匀速往另一侧推 | 推的每一帧 `D` 列都有数，符号和你推的方向相反 |
| 手停下 | `D` 立刻回 0，车恢复直行 |

"只在动的时候有、停了就没了"——这就是 D 的全部性格。

> ⚠️ **这个实验要看出东西，得让 `pos` 离开死区。** Day 37 实测：工作点 `pos ≈ +130` 躺在死区 150 里，`P` 本来就是 0，`D` 也只有 ±3~9，"带 P"和"只留 D"在日志上长得一模一样。要把道具推到 `|pos| > 150` 再按 `o`。

## 四、Kd 的五档

和 Kp 一样先跳五档试出现象，再微调。串口 `6`~`9`~`0` 直接跳，`d` / `f` 按 0.001 微调。

> ⚠️ **Kd 的键号和档位号错开一位**：`0` 才是"关"（0.000），`6` 已经是 0.005，`9` 才是最大的 0.040。Kp 那边键号 = 档位号，就 Kd 特殊。

| 键 | `Kd` | `Δpos=160/帧` 时的 d | 预期现象 |
|---|---|---|---|
| `0` | 0.000 | 0 | D 关，退回纯 P——先复现 Day 36 再往下走 |
| `6` | 0.005 | 8 | 轻阻尼，摆幅开始缩 |
| `7` | 0.010 | 16 | 中间档，通常最接近工作点 |
| `8` | 0.020 | 32 | 阻尼强，可能发僵、该拐不拐 |
| `9` | 0.040 | 64 | 噪声放大，轮子原地抖 |

**Kd 的上限不是"摆不摆"，是"噪声喂出来的 D 有多大"。** 这是它和 Kp 最不一样的地方：Kp 大了是"修得猛"，看得见；Kd 大了是"把传感器噪声放大成轮子抖动"，看起来像故障，不像参数问题。

所以今天加了一个命令 `n`：以控制周期采 30 帧，直接算出这一档 Kd 会把噪声放大成多大的 D 输出，并和当前 P 项的输出放一起比：

```
[n] 以控制周期 100ms 采 30 帧（约 3 秒）。车和线都别动。
[n] 这 3 秒电机保持当前 duty，别在这时候判断现象。
[n] 下面 30 行是纯 pos，直接喂 Python：
+365
+371
+360
...
  路   AO 最小   AO 最大   AO 摆幅
---------------------------------------------
  0      612       618         6
  1      588       595         7
  ...
  pos 摆幅      ：24（最小 +358，最大 +382）
  帧间最大 |Δpos|：12

  当前 Kp = 0.030，pos = +365  →  P 项输出 +11
  当前 Kd = 0.010，dt = 0.1s，最大 |Δpos| = 12
                    →  D 项输出 +1

  噪声喂出来的 D 是 P 的 0.12 倍
  → 这一档 Kd 安全，噪声还没被放大到能推动轮子。
```

判据（`n` 命令自己会打）：

| 噪声 D / P | 含义 |
|---|---|
| < 0.2 | 安全，噪声还没被放大到能推动轮子 |
| 0.2 ~ 0.5 | 临界，轮子会开始细抖，直道上能看见 |
| > 0.5 | 噪声占主导，轮子原地抖。Kd 太大，按 `f` 往小调 |

> ⚠️ **噪声 D 的比值只能和"同一环境、同一高度"下的另一次测量比。** 换张纸、换盏灯、动一下装车高度，`pos` 摆幅会整个变一个量级，比值也就跟着变。
>
> ⚠️ **比值里的 `P 项输出` 是没过死区的 P。** 工作点躺在死区里时（`|pos| ≤ 150`）实际 `P` 是 0，所以日志上那个 D/P 比值是偏乐观的——真实比例比显示得更大。判"安全"要看绝对值：`D` 输出是个位数、且明显小于巡航 duty，才叫安全。

## 六、串口命令

| 键 | 作用 |
|---|---|
| `c` / `b` / `w` / `t` | 标定白底 / 黑底 / 总表 / 量电位器阈值（Day 34 原样） |
| `p` | 曲线模式：每行 `pos / 压线路数×250 / turn / D` |

⚠️ 但**换环境 / 改光照 / 动过高度 → 白底会漂，必须重按 `c`/`b`**。

## 七、上机步骤

1. **先确认标定读到了**。上电应打 `[nvs] 已恢复上次的标定 + 方向 + Kp + Kd`，按 `w` 扫一眼量程还是昨天的数。
2. **先验方向**。道具压住 0/1 号，看 `L`/`R`——应该 `R < L`、右弧线；再压 3/4 号，应该 `L < R`、左弧线。**反了才按 `s`**（见 §二，符号取决于线的黑白）。
3. **先复现纯 P**。按 `0`（Kd = 0）、按 `3`（Kp = 0.030），道具压一侧看 `P` 列和 `L`/`R`。这是基线，后面所有对比都对着它。
4. **核心实验：D 只对变化率起作用**。道具**静止压住不动**，依次按 `6` → `7` → `8` → `9` → `0`，每档停 3 秒看 `D` 列。**应该五档全是 0**——偏差不动，D 就不动，和 Kd 多大无关。这是今天唯一能在架起上完全做完的核心实验，也是理解 D 项的钥匙。
5. **手推看阻尼方向**。停在 `7`（Kd = 0.010），道具压住不动 → 手匀速往另一侧推 → 立刻停住。推的每一帧 `D` 有数且符号和推动方向相反；手一停 `D` 回 0。
6. **量噪声**。保持在跟线态（不是五路全黑），按 `n`，记下 `pos` 摆幅、帧间最大 `|Δpos|`、D 项输出、噪声 D/P 比值。再按 `8` 按一次 `n`，再按 `9` 按一次 `n`——三次比出"哪一档 Kd 还没把噪声放大到能推动轮子"。
7. **只留 D**。把道具推到 `|pos| > 150`（离开死区，否则 P 本来就是 0、看不出区别），按 `o`，推一下看车动不动，再按 `o` 恢复。
8. **P + D 一起调** ⏳。要地面跑：同一段直道，先纯 P 录一段（看摆幅），再加 D 录一段（看摆幅缩了多少）。

**第 2 ~ 7 步架起就能做完，是今天真正的产出。** 第 8 步和 Day 36 的地面项一样欠着（电池带不动 + 没有贴黑赛道），回头一起补。

**但这个态比真线边缘安静得多**：四路深黑、一路深白，质心被钳死。作为对照，第一版日志里那个"线边缘正好压在传感器上"的静止跟线段，帧间最大 `|Δpos|` 是 **16**（这里是 5）。所以 0.020 只能当上限，工作点取 **0.010**。

### 顺手发现的一个硬件疑点

**0 号 DO 判黑门槛比以前低了。** 第二版日志里 0 号 DO 全程判 1，连 AO 已经掉到 226（白底标定 229）的时候还判黑；第一版日志里 0 号 DO 在 AO = 163 时能判白。`pos` 用 AO 算，不受影响，但 `[...]` 帧型第一位不可信（所以上表"白卡压 0/1 号"那行的帧型 `[1 0 1 1 1]` 实际是 `[0 0 1 1 1]`）。查 0 号 DO 线（GPIO1）和电位器。

## 九、还欠的

- ⏳ **P+D 摆振衰减没测**。架起只能证明"D 只对变化率起作用、且噪声没被放大到危险区"，衰减效果必须地面跑。Day 36 的地面项（工作点、duty 130 复核）和这项是一批，回头一起补。
- ⏳ **电池盒带不动车**。Day 35 起就欠着。D 项对帧间隔敏感——动力不足时车一冲一冲，`Δpos` 里会混进电源纹波，`Kd` 会调到一个假工作点。
- ⏳ **白底漂移**。台架不动都在漂（线正压 2 号时 `pos` 已有 −169 偏置）。D 项吃的是 `Δpos`，**漂移本身不喂 D**（漂是慢变量），但漂会让工作点整体偏移。每次跑前重按 `c` 再按 `b`。
- ⏳ **路4 饱和**。AO 能读到 3951（黑底 921），`n[4]` 过 1 还涨。这一路不光拽质心，还会让 `pos` 跳变——而 `pos` 跳变正是 D 的输入，等于给 D 喂假变化率。
- 📌 500ms 丢线超时仍是推理值。
