## 一句话总结

> **ESP32-S3 靠 TB6612FNG 驱动两个 TT 马达做差速转向，用 HC-SR04 超声波当眼睛测障碍、MPU6050 当内耳感知自身转了多少、SG90 当脖子让超声波左右扫描，最终实现"一直往前走，遇到障碍就停下观察两边，挑空的一边绕过去"的自主避障小车。**

## 三个最容易搞混的点

### ① 转向靠差速，不靠舵机

你这套是**万向轮**（从动轮，自己会跟着滑，拧不了方向）：

```
左转   = 左轮慢/停，右轮快
右转   = 右轮慢/停，左轮快
原地转 = 两轮反向等速
```

纯软件控制，零额外硬件。

### ② SG90 是给超声波当云台

HC-SR04 探测锥角只有约 15°，装死在车头只看得到正前方。架在舵机上才能左右扫：

```
        [ 超声波 ]
             |
          [ SG90 ]   ← 左右 -90° ~ +90°
             |
      ┌──────────────┐
      │   ESP32-S3   │
      └──────────────┘
       ⚫轮            ⚫轮
```

Day 21 进阶行为：遇障碍 → 停 → 左看右看 → 选空的一边绕过去。

### ③ 超声波 = 眼睛，IMU = 内耳

| 模块 | 感知对象 | 类比 |
|------|---------|------|
| HC-SR04 | **外部环境**（前面有没有墙） | 眼睛 |
| MPU6050 | **自身状态**（我转了多少度、在不在坡上） | 内耳 / 平衡觉 |

两者不可替代、也不重复。

## 采购与硬件备注

- **底盘套件自带**：TT 马达 1:48 ×2、左右车轮、1寸万向轮 ×2、测速码盘 ×2、3V 电池盒（2 节 5 号）、M3 铜柱/螺丝/螺母、红黑并线 ×2
- **套件不含**：任何单片机、任何驱动芯片、任何传感器 —— 纯机械件，必须配 ESP32 + TB6612FNG 才能动
- **额外购 6V 电池盒**（4 节 5 号）作主力电源：TT 马达在 3V 下转速约为 6V 的一半
- ⚠️ **共地铁律**：ESP32 与电池盒必须 GND 相连，否则 PWM/方向信号没有参考电平，马达会乱转或不转
- ⚠️ **TT 马达无编码器引线**（码盘需配光电对管，套件不含）→ Day 19/21 只能是**开环 PWM 调速**；闭环测速需另购编码器模块（Day 28 范畴）
- 💡 **省 GPIO 技巧**：TB6612FNG 的 **STBY 直接接 3.3V** 常高，少占用一个 GPIO
