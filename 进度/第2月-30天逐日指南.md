## 第1周：中断与循线机器人（Day 31-38）

### Day 31：中断——反应计时游戏
**目标**：理解轮询和中断的区别；编码器读数必须用中断，今天先把中断吃透

**任务**：
1. 用现有件搭反应计时：按键 + 外接 LED（GPIO2）
2. LED 随机延迟后亮起（`random()` 加 `randomSeed(analogRead(...))`），按键停止计时，毫秒级输出到串口
3. 按键用 `attachInterrupt()` 边沿触发，**不用** `digitalRead()` 轮询
4. 记录"轮询版"和"中断版"的最短可测反应时间差异

**代码参考**：
```cpp
const int BTN = 1;
const int LED = 2;
volatile bool pressed = false;
unsigned long t0, t1;

void IRAM_ATTR onPress() { pressed = true; }  // ESP32 中断处理函数必须在 IRAM

void setup() {
  Serial.begin(115200);
  pinMode(BTN, INPUT_PULLUP);
  pinMode(LED, OUTPUT);
  attachInterrupt(digitalPinToInterrupt(BTN), onPress, FALLING);
  randomSeed(analogRead(1));
  delay(random(2000, 5000));
  digitalWrite(LED, HIGH);
  t0 = millis();
}

void loop() {
  if (pressed) {
    t1 = millis();
    digitalWrite(LED, LOW);
    Serial.printf("reaction = %lu ms\n", t1 - t0);
    pressed = false;                 // 清标志
    delay(200);                      // 消抖
    delay(random(2000, 5000));
    digitalWrite(LED, HIGH);
    t0 = millis();
  }
}
```

**要弄清的三个坑**：中断里不能 `Serial.print` / `delay`；共享变量要 `volatile`；ESP32 的中断处理函数要加 `IRAM_ATTR`。

**输出**：两个版本的最短可测反应时间对比 + 中断三坑的记录

### Day 36：P 控制
**目标**：把方向误差变成连续的转向量——这也是本项目第一个闭环

**任务**：
1. `turn = Kp × pos`，映射到左右轮 duty 差

### Day 37：加入 D 项
**目标**：完成原始计划的"P 之后加 D"，让摆振停下来

**任务**：

## 第2周：姿态融合（Day 39-45）

### Day 39：按数据手册裸读 I2C 传感器
**目标**：完成里程碑"无需教程、根据数据手册连接和读取 I2C 传感器"——这次不装库

**任务**：
1. 打开 MPU-6050 的数据手册，只查三件事：`WHO_AM_I`（0x75，应回 0x68）、`PWR_MGMT_1`（0x6B，写 0 唤醒）、加速度计配置寄存器（0x1C，选 ±2g）
2. 用 `Wire` 直接读，**不引入 Adafruit_MPU6050**
3. 先读 `WHO_AM_I` 校验地址没错再往下走
4. 换算成 g：量程 16384 LSB/g（±2g）
5. 和第 1 月用库读出的值逐位对比，确认裸读没错

**代码参考**：
```cpp
#include <Wire.h>

const uint8_t MPU = 0x68;            // AD0 接 GND 时的地址

void writeReg(uint8_t reg, uint8_t val) {
  Wire.beginTransmission(MPU);
  Wire.write(reg); Wire.write(val);
  Wire.endTransmission();
}

uint8_t readReg(uint8_t reg) {
  Wire.beginTransmission(MPU);
  Wire.write(reg);
  Wire.endTransmission(false);       // 不释放总线，后面还要读
  Wire.requestFrom(MPU, (uint8_t)1);
  return Wire.read();
}

void setup() {
  Serial.begin(115200);
  Wire.begin();
  writeReg(0x6B, 0x00);              // 退出睡眠
  // writeReg(0x1C, 0x00);           // ±2g
  Serial.printf("WHO_AM_I = 0x%02X (expect 0x68)\n", readReg(0x75));
}

void loop() {
  Wire.beginTransmission(MPU);
  Wire.write(0x3B);                  // 加速度数据起始寄存器
  Wire.endTransmission(false);
  Wire.requestFrom(MPU, (uint8_t)6);
  int16_t ax = Wire.read() << 8 | Wire.read();
  int16_t ay = Wire.read() << 8 | Wire.read();
  int16_t az = Wire.read() << 8 | Wire.read();
  Serial.printf("%.3f %.3f %.3f g\n", ax/16384.0, ay/16384.0, az/16384.0);
  delay(200);
}
```

**输出**：裸读 vs 库读的对比数据 + 数据手册里查到的三个寄存器地址截图/摘录

### Day 40：俯仰角与静止漂移

## 第3周：编码器闭环（Day 46-51）

### Day 46：编码器——从脉冲到角度
**目标**：看懂光电编码器的输出，能用中断数对脉冲

**任务**：
1. 读所购编码器电机的规格：**每转脉冲数**（ppr）× **减速比** = 输出轴每转脉冲数；分清"电机侧"和"轮子侧"
2. 接线：编码器 A/B 两相 → GPIO（优先 34–39 输入专用脚，但中断脚均可）；电机仍由 TB6612 驱动
3. `attachInterrupt()` 挂在 A 相 `RISING`，每中断计数 +1
4. 用手把轮子精确转一圈，核对计数与标称值是否吻合；不吻合就说明倍频/减速比理解错了

**代码参考**：
```cpp
const int ENC_A = 4;
volatile long ticks = 0;

void IRAM_ATTR onEnc() { ticks++; }

void setup() {
  Serial.begin(115200);
  pinMode(ENC_A, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(ENC_A), onEnc, RISING);
}

void loop() {
  static long last = -1;
  if (ticks != last) {
    last = ticks;
    Serial.printf("ticks = %ld\n", ticks);
  }
}
```

**输出**：手动转一圈的 `ticks` 值 × 3 次，验证可重复性

### Day 47：转速换算与分辨率
**目标**：把 `ticks` 变成 rpm，并知道这套装置的精度上限在哪

**任务**：
1. `rpm = ticks / ticksPerRev × 60 / 采样间隔秒`
2. 用固定间隔（如 100ms）采样计数差值，而非累计值——累计值在 `millis()` 溢出和除零上都容易出错
3. 加 B 相判向：`ticks` 可正可负，正转 +1、反转 −1
4. 测同一 duty 下的 rpm 稳定性，记录方差；思考分辨率 = `60 / ticksPerRev / 采样间隔` 这个下限是什么决定的

**输出**：`duty → rpm` 对照表（duty 100/150/200/255）× 3 次采样的离散度

### Day 48：占空比 ≠ 转速
**目标**：把第 1 月"DUTY 180 电机不转"的体感变成曲线

**任务**：
1. 固定 duty，记录 rpm；扫 duty 100→255 画曲线
2. 换上电压不同的电池（或加电阻模拟压降），重扫一遍
3. 两条曲线对比：**同一 duty 下转速随电压变化**——这就是开环调速不可靠的量化证据
4. 找出"转速开始明显偏离线性"的 duty 区间

**输出**：`duty → rpm` 曲线（两种电压各一条）+ 结论

### Day 49：P 速度环
**目标**：第一个速度闭环：给目标转速，让系统自己跟上

**任务**：
1. `error = target - measured`，`duty = duty_prev + Kp × error`（增量式）或 `duty = Kp × error`（位置式），先做增量式更稳
2. 采样间隔 100ms；`Kp` 从小到大试，观察过冲/振荡
3. 限制积分饱和：`duty` 夹在 0–255
4. 换电池电压，看目标转速是否还能维持——**闭环的意义在这一刻才成立**

**输出**：闭环前后"目标 200rpm"的实测误差对比

### Day 50：精确转一整圈
**目标**：完成里程碑"无论电池电压如何都能精确旋转一整圈"

**任务**：
1. 目标不是速度而是**位置**：累计 ticks 到 `ticksPerRev` 就停
2. 引入 **I 项**：纯 P 的稳态静差（轮子有摩擦和死区，到不了位）
3. 刹车方式：到位置 `HIGH/HIGH` 刹住，而不是 `LOW/LOW` 滑行
4. 用三种不同电池状态各测 5 次，看落点分布

**输出**：三种电池状态下"转一圈"的误差表，说明 I 项解决了什么

### Day 51：第 3 周项目——编码器测速 + 定圈数停车
**目标**：把本周内容合成一个能演示的固件

**任务**：

## 第4周：自平衡机器人（Day 52-58）

### Day 52：自平衡的原理
**目标**：想清楚再动手——这是个和循线完全不同的控制问题

**任务**：
1. 倒立摆：车竖着时稳定点在正上方，**任何偏离都会自我放大**
2. 控制的不是"去哪里"，而是"不要倒"：平衡环优先级 > 位置环优先级
3. 明确两条环的职责：角度环决定要不要走，速度环决定走多快（走的指令最终变成**目标角度的偏移**）
4. 在第 2 周记录的基础上想：`α`、`dt`、采样率各自会影响什么

**输出**：两级控制的框图 + 每条环的输入输出表

### Day 53：换装编码器电机与供电复核
**目标**：自平衡车要换成带编码器的电机，先确认扛得住

**任务**：
1. 装编码器电机 + 轮子；编码器接 Day 46-47 用过的脚，电机仍由 TB6612 驱动
2. **供电复核**：两路电机同时启动的峰值电流，用万用表串电池测一次；6V 电池盒内阻若导致压降 > 0.5V，上锂电池或加容
3. 重心：MPU-6050 尽量装在高处、靠近轮轴中垂面，远离电机（电机是最大振动源）
4. 上电前万用表通断档查一遍电源短路——这是第 1 月养成的规矩

**输出**：峰值电流实测值 + 压降判定 + 整备照片

### Day 54：第一版：让车不倒
**目标**：先把角度环立起来，不管位置

**任务**：
1. `duty = Kp_ang × angle + Kd_ang × gyro`（只用角度误差和角速度，位置环先不接）
2. 角度误差定义为"偏离竖直的小角度"，`angle > 0`（前倾）→ 前进，`angle < 0` → 后退
3. 先用手扶着车，让它以极小角度试探；再松手
4. 预期第一次一定失败：要么冲出去，要么直接倒——记录是哪一种，它指出 `Kp_ang` 是太大还是太小

**输出**：第一版表现 + 失败模式判定（冲 / 倒）

### Day 55：调 P 让它站起来
**目标**：完成自平衡最难的一步

**任务**：
1. `Kp_ang` 从极小开始，每次加一点，记录"能站几秒"的阶梯
2. 站不稳时先查三件事：角度符号方向对不对、`dt` 抖动、MPU-6050 是否被电机干扰
3. 站住 5 秒就记一笔，做成阶梯表
4. 到能站 30 秒，`Kp_ang` 与 `Kd_ang` 各记录一个工作值

**输出**：能站立时长的阶梯表 + 两个 `K` 的工作点

### Day 56：速度环与位置回正

**任务**：

## 附录：常见问题与排障

### 编码器

**Q: ticks 数不对，差很多或差一半**
- 减速比与编码器 pp 数弄混：标称的脉冲数通常是**电机侧**，除以减速比才是轮子侧
- A 相单沿计数只拿到 1/4 分辨率：要四倍频得同时读 B 相，或在硬件上两相都中断
- 接线松动或没加上拉：GPIO 悬空在电机旁最容易乱跳，务必上拉 + 尽量屏蔽

**Q: 一开电机 ticks 就狂跳**
- 电机是巨大噪声源。编码器线远离电机线，加 100nF 去耦，或在代码里加软件滤波（连续 N 次同值才认）

**Q: 转速曲线开始振荡，duty 上下跳**
- `Kp` 过大，或采样间隔不固定。`dt` 必须用 `millis()` 差值实时算，不能写成常量

### 姿态融合

**Q: 静止也漂移**
- 零偏没校：静止采 2000 次求均值再减掉
- `dt` 用了固定值：积分项必须乘真实 `dt`
- 加速度计被振动干扰，选错 `α`

**Q: 一动就跟不上，角度迟钝**
- `α` 太低，过度信任加速度计。加速度计不该信"快"的那部分

**Q: MPU-6050 一接电机就乱**
- 电机振动通过底盘直接传到传感器。软隔离（海绵/减震垫）+ 远离电机安装

### 自平衡

**Q: 一松手就冲出去**
- `Kp_ang` 太小或角度反了。先用极小的 duty 试探方向

**Q: 站一下就开始大幅摆**
- `Kd_ang` 不足或 D 项把噪声放大了。先把陀螺仪降采样或低通，再加 D

**Q: 车能平衡但不听遥控**
- 速度环输出没接进角度目标，或速度环优先级盖过了角度环

**Q: 平衡了十几秒突然倒**
- 电池压降导致 duty 饱和，或电机持续堵转过热。看 Day 53 记的压降数据

### 焊接与调试

**Q: 焊点不牢、冷焊**
- 烙铁温度不足或焊面氧化；焊前镀锡，焊后用放大镜检查

**Q: 上电无反应**
- 万用表通断档查电源短路，这是唯一手段；别反复上电
