# Day 38 — 第 1 周项目：调参对比

## 一、原计划 vs 现在怎么弄

指南要的是：同一段赛道录三段视频（开环 / P 过大 / P+D 调好），同速度同电池，写清每个参数的现象、最终取值和为什么。

地上跑不了（电池盒带不动车），所以改成**架起 + 按按键 + 看日志**：同一个固件、同样的三段配置、同样的推卡动作，只是把"车跑"换成"手推白卡"。能量出同样的东西，而且日志比视频更好比。

> ⚠️ 代价一句话：这样量到的是**控制器的输出**（`turn`），不是车的动作。摆振衰减的最终数字还得等地上跑。

## 二、操作步骤

**准备**：车架起（轮子悬空）、USB 插电脑、串口监视器 115200、一张白卡。

1. 上电，等它打 `[nvs] 已恢复上次的标定 + 方向 + Kp + Kd`。没这行就先按 `c`（白底）再按 `b`（黑底）。
2. **验方向**：白卡压住 0/1 号 → 日志应 `R < L`；压住 3/4 号 → 应 `L < R`。反了才按 `s`。
3. **第一段 A 开环**：按 `0`（Kd 归零），再按 `o`（Kp 归零）。然后做推卡动作：
   **白卡压住 3/4 号 → 匀速推到 0/1 号（约 2 秒）→ 停 1 秒 → 匀速推回来。来回 3 次。**
   录 10 秒日志，存成 `A-开环.txt`。
4. 按 `o`（把 Kp 恢复回来）。
5. **第二段 B P 过大**：按 `5`，再按 `6`。**用和第 3 步一模一样的推法**。存成 `B-P过大.txt`。
6. **第三段 C P+D 调好**：按 `3`，再按 `7`。还是同样的推法。存成 `C-PD调好.txt`。

**三段推卡的手法必须一样**——输入相同，`turn` 才能比。

## 三、看哪一列

帧日志里只看 `turn`：

```
[1 1 1 0 0] n=4 | raw ... | pos −446   P  −13 D   +0 turn  −13 L128 R102 左弧线
                                              ─┬─       ─┬─
                                              P项     之和=实际给轮子的量
```

| 段 | 按键 | `turn` 应该是什么样 | 说明什么 |
|---|---|---|---|
| A 开环 | `0` `o` | 全是 0 | 没有纠偏项，偏出去没有任何东西把它拉回来 |
| B P 过大 | `5` `6` | 大幅跳，一侧轮子 duty 掉到很小 | 修得猛，等效于 Day 35 那个来回摆的根 |
| C P+D | `3` `7` | 峰值明显比 B 小 | D 把"正在变"的那部分抵掉了，这就是阻尼 |

**按键和档位号错开一位，别按顺口了：**

| Kp | `1` | `2` | `3` | `4` | `5` |
|---|---|---|---|---|---|
| 值 | 0.005 | 0.015 | 0.030 | 0.060 | 0.120 |

| Kd | `0` | `6` | `7` | `8` | `9` |
|---|---|---|---|---|---|
| 值 | 0.000 | 0.005 | 0.010 | 0.020 | 0.040 |

Kd 的"关掉"在 `0` 键上，`6` 已经是 0.005 了；要 0.010 得按 `7`。Kp 倒是键号 = 档位号。
`o` 把 Kp 临时归零只留 D（再按一次恢复）。

> **`o` 会把 `Kp = 0` 存进 flash**，但 `loadPrefs()` 有 `if (kpNum == 0) kpNum = kpNumSaved;` 兜底，下次上电自动带 P 起来，不会一开机就不巡线。录完 A 段按一次 `o` 恢复即可。

## 四、最终取值与为什么

| 参数 | 取值 | 为什么 |
|---|---|---|
| `Kp` | **0.030**（第 3 档） | Day 36 五档 `turn` = 1/5/10/22/41 全在线性区；第 3 档左右轮 duty 差 48/255 ≈ 19%，和 Day 35 的 `115−75 = 40` 同量级，那个量级跟住过 18 秒 |
| `Kd` | **0.010**（按 `7`） | **Kd 的上限不是"摆不摆"，是"噪声喂出来的 D 有多大"**：0.040 → 比值 0.50 太大、0.020 → 0.25 临界、0.010 → 0 安全。而那个"临界"是在四路深黑一路深白的安静态下量的，真线边缘帧间 `\|Δpos\|` 从 5 涨到 16，D 输出会涨 3 倍直接过 0.5 |
| 巡航 duty | **115** | 转向量的上限就是巡航 duty；Day 35 唯一跑出连续跟线的那一档 |
| 死区 | **150** | 白底漂移台架不动就有 312 码摆幅 = 死区两倍，再小等于为漂移白修 |
| `steerSign` | **+1**（当前 flash） | 由线的黑白决定，不是常量——黑道具压白底要 −1，白卡压黑底要 +1。贴黑赛道在白底上跑之前必须先按一次 `s` |

> ⚠️ **0.030 是起点不是结论。** 架起轮子悬空测的；地上有负载，同样 duty 对应的修正量会变小，"哪一档不摆"必须地面跑才能定。

## 五、上机结果

三段都录了，配置全部正确（Kd 的键号和档位号错开一位这个坑踩过两次，见 §三）：

| 段 | 配置 | `pos` 范围 | `|P|` 峰值 | `|D|` 峰值 | `|turn|` 峰值 | 最低轮 duty | 限幅帧 |
|---|---|---|---|---|---|---|---|
| A 开环 | `Kp=0, Kd=0` | −656…+358 | 0 | 0 | **0** | 115 | 0 |
| B P 过大 | `Kp=0.120, Kd=0.005` | −832…+825 | 99 | 58 | **115** | **0** | **2** |
| C P+D 调好 | `Kp=0.030, Kd=0.010` | −754…+475 | 22 | 26 | **33** | 82 | 0 |

### 三个配置说明什么

1. **没有纠偏项，偏出去就毫无反应**（A）。345 帧 `P`、`D`、`turn` **全是 0**，两轮一动不动给 115/115，而 `pos` 已经甩到 −656…+358（远超死区 150）。P 是唯一能把车拉回线里的项，D 只让"正在变"的部分衰减。
2. **P 太大就是猛修**（B）。`|P|` 峰值 99，`turn` 顶到 ±115 限幅，两帧打出 `← turn 限幅：内轮停转`，轮子 duty 掉到 0。Day 35 那个来回摆的根。
3. **P + D 调好就是把它按住**（C）。同样量级的推卡，`|turn|` 峰值从 B 的 **115 掉到 33**（3.5 倍），最低轮 duty 从 **0 回到 82**，限幅帧和反向各归零。

> B 的推卡幅度略大于 C（`pos` 摆幅 1657 vs 1229），但 `|P|` 峰值 99 vs 22 正好是 Kp 0.120/0.030 的 4 倍——说明 B/C 的差距全部来自 Kp，不是来自推法。C 的优势是实打实的。

### 顺带：Kd 0.020 为什么会发僵

C 段第一遍按错了键，实际跑的是 `Kp=0.030, Kd=0.020`：`|D|` 峰值 **95**、`|turn|` 峰值 107、轮 duty 掉到 8——和 B 的 115 只差一点，阻尼完全没起到"按住"的作用，反而成了第二个猛修的项。

Day 37 从**安静态的噪声比**推出 0.020 是临界档，Day 38 从**真大幅快推**看到它过冲——两条独立证据指向同一个档位。工作点取 0.010。

Day 35 的基线可参照：摆动 0.49 次/秒（约 2 秒一周）、摆幅 `pos` ±800、静差常驻 +400、29 次刹停、最长连续跟线 18 秒。

## 六、还欠的

- ⏳ **摆振衰减的量化对比**。架起量到的是 `turn` 输出，车的实际摆幅必须地上跑。
- ⏳ **`Kp` 最终档位**。0.030 只是起点。
- ⏳ **电池盒带不动车**。Day 35 起欠着：架起那次只能 USB 供电，地上跑靠残存动力挪完的。动力不足会同时污染速度、duty 响应和丢线超时三项——先换电池 / 查电机堵转 / 量实际工作电压。
- ⏳ **白底漂移**。台架不动都在漂（线正压 2 号时 `pos` 已有 −169 偏置，312 码摆幅 = 死区两倍）。P 会把这个偏置当误差去修，等于白送一个固定转向量。每次跑前重按 `c` 再按 `b`。
- ⏳ **路4 饱和**。AO 读到 3951（黑底才 921），`n[4]` 过 1 还涨，`W[4]=2` 再放大两倍。这一路不光拽质心，还会让 `pos` 跳变——而 `pos` 跳变正是 D 的输入。
- ⏳ **0 号 DO 门槛漂低**。GPIO1 的电位器要重对，否则帧型第一位不可信。

## 七、⏭️ 进阶：地面跑怎么补

架起这套已经把"控制器的输出"量清楚了。真要跑起来，还差四样前置和一套监测办法。

### 前置条件（缺一样都白跑）

| 项 | 要什么 |
|---|---|
| 电池 | 带不动车一切免谈。换电池 / 查电机堵转 / 量实际工作电压 |
| 道具 | 白纸 + 黑线。黑电工胶带贴白纸最省；线宽接近五路探头的间距，线和白底要能同时被压到 |
| 距离 | **至少 3-5 米**。Day 35 那个 2 秒一周的摆，一米内只够摆一次，看不出衰减趋势 |
| 极性 | 黑赛道在白底上跑，上线前先按一次 `s`——flash 现在存的 `+1` 是给"白卡压黑底"用的 |

### 监测：不用无线遥控，USB 串口就是遥测

这是关键——**不用像以前那样靠遥控边跑边看**。跑的时候电脑开着串口，帧日志一帧不落全存下来，跑完直接分析：

- 日志里每一帧都有 `pos / P / D / turn / L / R`。把 `pos` 当时间序列画出来，**摆幅、摆动周期、刹停次数、最长连续跟线、静差**全都算得出来，不用回忆"刚才那下摆得厉害不厉害"。
- Day 35 已经有一套基线数字可以直接对比：摆动 0.49 次/秒（约 2 秒一周）、摆幅 `pos` ±800、静差常驻 +400、29 次刹停、最长连续跟线 18 秒。
- 视频只作辅助，用来把"日志哪一段"对到"视频哪一段"。板载 RGB 可以拿颜色表示状态（跟线 / 丢线 / 刹停），两边就能对齐。
- 想彻底摆脱 USB 线：**ESP32-S3 自带 WiFi**，加几十行把帧日志 UDP 广播出去，电脑端 `nc -ul 115200` 收。车彻底自由活动、日志实时回传——这就是"跑的过程全记下来传回电脑分析"。要新固件，Day 39 之后有空再做。

### 要补的对比

- 同一段直道录**纯 P**（`0`）和 **P+D**（`3`+`7`）两段，比 `pos` 摆幅缩了多少——Day 37 §八 那张空表就是填这个的。
- `Kp` 逐档试，看哪一档不摆（架起的 0.030 只是起点，地上有负载，同样 duty 对应的修正量会变小）。

### 架起侧还能再抠一点
