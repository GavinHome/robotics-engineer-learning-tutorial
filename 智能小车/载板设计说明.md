# 智能小车载板 · 设计说明（v2 模块级）

> EasyEDA Pro 工程「智能小车」→ Board1 / Schematic1 + PCB1
> **设计理念**：不重造轮子。四块成品模块各留一组母座，插上去就能用，板上零芯片、零阻容。

## 一、这块板是什么

把 Day 21/24 那辆面包板小车的连线固化到一块 90×65mm 的板上：

| 位号 | 母座/端子 | 插什么 | 位置 |
|---|---|---|---|
| J1+J2 | 2×20P 排母 @2.54（排距 22.86mm） | **ESP32-S3 开发板**（整块插上） | 板子中部 |
| J3+J4 | 2×10P 排母 @2.54 | **TB6612FNG 驱动模块** | 板子右侧 |
| J5 | 4P 排母 @2.54 | **MP1584EN 降压模块** | 板子左侧 |
| J6 | 4P 排母 @2.54 | **HC-SR04 超声波模块** | **板前端正中（车头）** |
| J7 | 2P 接线端子 | 电池盒 6V | 板左下 |
| J8/J9 | 2P 接线端子 | 左/右 TT 马达 | 板右下 |

模块全部可插拔——开发板拔下来能单独烧录/调试，驱动模块坏了直接换。

## 二、网络表（母座之间的连接）

板子只有 16 个网络，和 Day 24 的接线完全一致：

| 网络 | 连接 | 说明 |
|---|---|---|
| GND | J1/J2 的 GND 针、J3/J4 GND、J5 GND、J6 GND、J7.2、J8/J9 一端 | 全板共地 |
| 3V3 | J1.1 → J3.3 → J5.3 → J6.1 | 降压输出供开发板；模块 VCC/STBY 也取这里 |
| VBT | J7.1 → J3.2 → J5.1 | 电池 6V：驱动模块 VM 直连 + 降压输入 |
| IO4 / IO5 | J1.3/J1.4 ↔ J6.2/J6.3 | 超声波 Trig/Echo |
| AIN1/AIN2/PWMA | J1.17/J1.18/J1.19 ↔ J3.4/J3.5/J3.6 | 左轮三线 |
| BIN1/BIN2/PWMB | J1.7/J1.8/J1.9 ↔ J4.3/J4.4/J4.5 | 右轮三线 |
| STBY | J1.1 → J3.8 | 驱动使能（接 3V3 常高） |
| AO1/AO2 | J3.9/J3.10 ↔ J8.1/J8.2 | 左电机 |
| BO1/BO2 | J4.6/J4.7 ↔ J9.1/J9.2 | 右电机 |

> 代码零修改：GPIO4/5=Trig/Echo、10/11/12=AIN、15/16/17=BIN、48=RGB，与 Day 21 草图一致。

## 三、当前状态与收尾（重要）

已完成：✅ 原理图（母座符号+网络标签）✅ PCB 布局（9 器件+板框 90×65）✅ 焊盘网络绑定（44 焊盘）✅ DRC 飞线正常显示

**未完成：铜箔走线**。AI 的脚本布线器在 2.54mm 针距密度下无法保证零短路，所以板子上只有飞线没有铜箔。

### 收尾方法（5 分钟，在 EasyEDA 里）

1. 打开工程「智能小车」→ PCB1（现在打开就能看到母座和飞线）
2. 框选所有器件（Ctrl+A）→ 菜单 **布线 → 自动布线**（或按 `Ctrl+F9`？实际是顶部工具栏「布线(R) → 自动布线」）
3. 弹窗里：布线层选「顶层+底层」、网络选「全部」、直接确定
4. 等几秒，EDA 自带布线器会沿着飞线把铜箔布好（它处理针距密度比脚本强）
5. **设计 → DRC 检查**：应为 0 错误；若有少量报错，点错误定位后按 `Delete` 删掉那段线，用 `X`（走线命令）沿飞线重连即可
6. 制造 → 导出 Gerber → 嘉立创下单

## 四、为什么不是"芯片级方案"

之前画过一版用裸片（TB6612 SSOP-24 + MP1584 SOIC-8 + ESP32 模组）的集成板，需要 35 颗阻容、FB 分压、补偿网络、USB 上下拉——那是"重新设计产品"。而你要的是"把手上的模块插到一块板上"，所以这一版全部用母座，零外围。

两版都在工程里；这一版（载板）是推荐做法。
