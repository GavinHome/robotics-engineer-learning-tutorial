## 一、这块板是什么

把 Day 21/24 的面包板小车（ESP32-S3 开发板 + TB6612 模块 + MP1584EN 模块 + 杜邦线）收进一块 66×56mm 的两层板：

| 区域 | 内容 |
|---|---|
| 主控 | ESP32-S3-WROOM-1-N16R8 贴片模组（天线伸出板边 4mm，净空无铜） |
| 电机驱动 | TB6612FNG 裸片（SSOP-24），驱动左右两个 TT 马达 |
| 电源 | 4×AA 6V 电池 → AO3401A 防反接 → 分两路：电机直挂 VBT；另一路经 SS34 防倒灌 → MP1584EN 降压 3.3V |
| USB | Type-C（CC1/CC2 带 5.1k 下拉），USB 数据直连 GPIO19/20（内置 USB-Serial-JTAG，免驱动烧录） |
| 供电仲裁 | USB 5V 经 SS34 与电池 6V 二极管或，电池在车、USB 在桌都能用 |
| 传感/扩展 | HC-SR04 四针、UART 调试四针、I2C+ spare 六针、舵机三针（VM 供电） |
| 其它 | WS2812B 状态灯（GPIO48）、电源 LED、EN/BOOT 按键、电池电压分压采样（GPIO1） |

**引脚与 Day 21 代码完全一致**：Trig=4 / Echo=5 / AIN1=10 / AIN2=11 / PWMA=12 / BIN1=15 / BIN2=16 / PWMB=17 / RGB=48。现有超声波避障草图不改一行即可用。

新增（代码要加，不是改）：
- 电池电压采样：GPIO1（ADC），分压 VBT×(100k/220k)
- I2C：SDA=GPIO8、SCL=GPIO9（给 MPU-6050 留）
- 舵机：GPIO7（PWM）
- 备用：GPIO2、GPIO21 已引到扩展排针

## 三、焊接顺序（由低到高）

1. 全部 0805 电阻电容（35 颗）→ 2. SS34×3、AO3401A、LED → 3. TB6612（SSOP-24，拖焊）→ 4. MP1584EN（SOIC-8）→ 5. WS2812B → 6. USB-C → 7. 电感 CD54、470µF 电解（**看极性**）→ 8. 排针、接线端子、按键 → 9. 最后贴 ESP32-S3 模组（回物流焊/风枪最佳；用电烙铁拖焊亦可，模组焊盘大）。

上电前：万用表通断档查 VBT-GND、3V3-GND 无短路 → 装电池量 3V3 = 3.2~3.35V → USB 上电看串口。

## 五、⚠️ 已知问题（下单前必须处理）

通过 API 驱动 EDA 有两个本版本限制，留下的收尾工作都在 GUI 里做（打开工程即可见）：

### 1. 走线短路 25 处（必须修）

自动布线在两个拥挤走廊留下短路。**DRC 面板（设计 → 检查 DRC）里全部可见**，逐个手工修改（每处把其中一条走线拖开绕行即可）。当前清单（网络对）：

**USB 口上方（J8 排针与 R11/R12 之间，y≈7.4mm 一带）— 6 处**
- VBUS ↔ CC1、VBUS ↔ CC2（×2）、VBUS ↔ USB_DP、USB_DM ↔ SW_BO1

**TB6612 上方（U2 与模组之间，y≈27mm 一带）— 7 处**
- VBT ↔ PWMA（×2）、VBT ↔ AIN1、3V3 ↔ AIN1、3V3 ↔ VBT、PWMA ↔ AIN2、3V3 ↔ GND

**板中部/右侧 — 12 处**
- SR04_ECHO ↔ IO46、IO46 ↔ BIN2、IO46 ↔ SR04_TRIG、EN ↔ UART_RX（×2）
- SW_BO2 ↔ GND（×4）、SW_BO2 ↔ USB_DM、SW_BO2 ↔ SW_AO2（×2）、SW_BO2 ↔ SW_BO1
- SW_AO1 ↔ I2C_SCL、3V3 ↔ VBT

> 这些短路集中在两处 50mil 高的走廊里，是布局密度与自动布线粒度的共同结果。修法：DRC 面板双击错误定位 → 把两条相碰走线中较短的一条删除 → 手工重画绕行（底层绕行时注意避开 GND 铺铜以外的走线）。修完重跑 DRC 到 Clearance Error = 0。

### 2. 走线已全部连通 ✅

I2C_SCL（模组 IO17 → 扩展排针）与 IO46（模组 IO16 → R3）的绕行走线已补齐（多层跳线），无需处理。

### 3. 网络名未附着到焊盘（可忽略）

本 EDA 版本的「原理图转 PCB」API 无法在无界面模式下完成，焊盘网络名为空。后果：DRC 会有大量「焊盘-走线」提示（几百条，全部是同一原因）+ 无飞线显示。**不影响 Gerber 输出和制板**——铜箔连接本身是完整的。想消掉这些提示：在 GUI 里选中全部走线重布或手动为焊盘指定网络即可。

### 4. 原理图与 PCB 的关系

原理图是完整可读的设计文档（元件、网络标签、电源旗齐全）。因为 API 创建的导线在编辑器内部不携带连接属性，**原理图转 PCB 不会生成增量**——PCB 的正确性由本文档的网络表（见下）保证。改网络时请原理图与 PCB 同步手改。
