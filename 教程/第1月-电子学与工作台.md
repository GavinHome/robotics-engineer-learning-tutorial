# 第1个月：电子元件、工作台以及你用来制作一切的工具

## 本月目标
能够读懂电路图，搭建一个能正常工作的电路，并在电路出现故障时找出问题所在。

---

## 1. 电子学基础知识

### 需要了解的概念
- 欧姆定律、分压器
- 电容器的作用
- 晶体管的开关原理
- 如何读懂电路图（电阻器、电容器、二极管、晶体管、接地、Vcc）
- 上拉电阻和下拉电阻
- 去耦电容：为什么每个集成电路都需要一个
- 电池化学基础：锂聚合物电池的电芯数量、C倍率、充电安全

### 学习资源
1. **Falstad 电路模拟器**（免费，浏览器内）
   - https://www.falstad.com/circuit/
   - 动画化电子流动和实时电压着色

2. **Tinkercad Circuits**（Autodesk，注册免费）
   - https://www.tinkercad.com/circuits
   - 虚拟面包板、虚拟Arduino、虚拟万用表

3. **All About Circuits  Textbook**（免费）
   - https://www.allaboutcircuits.com/textbook/
   - 完整开源电子工程教材，共六卷

4. **Afrotechmods 教程**（免费）
   - https://afrotechmods.com/tutorials/
   - 短小精悍，按初级、中级、高级分类

5. **《Make: Electronics》第三版**，Charles Platt（$29.99）
   - https://www.makershed.com/products/make-electronics-3rd-edition-print
   - 围绕故意损坏元件来了解其极限

### 练习任务
- 在 Falstad 中搭建分压器，手动计算输出电压，仿真验证
- 搭建晶体管开关，3.3V 微控制器引脚控制大电流电路
- 用万用表测量真实电阻、电池电压、检测导线通断

## 2. 工作台、工具及预算

### 第0级：$0
先学习 Falstad、Tinkercad 和 All About Circuits，掌握欧姆定律和分压器后再花钱。

### 第1级：$45–60
- Elegoo UNO R3 超级入门套装（$42.99）
  - https://www.elegoo.com/products/elegoo-uno-r3-super-starter-kit
- Adafruit 9205B+ 数字万用表（$17.50）
  - https://www.adafruit.com/product/2034

### 第2级：$110–160
额外购买：电烙铁、焊锡、斜口钳、剥线钳、辅助夹、万用板、额外被动元件

### 第3级：$200–300
台式电源、更好万用表、吸锡泵、储物抽屉、机器人底盘套件

### 订购建议
- 第一次下单从亚马逊或 Elegoo 区域仓库购买，几天内到手
- 熟悉后从 AliExpress 订购散件（便宜3–10倍，但等2–6周）

### 练习任务
购买测试工具包和万用表，测量5个随机电阻并对照色环检查，用导通模式检测故意断开的导线。

## 3. 焊接

### 学习资源
1. **Adafruit 优秀焊接指南**（免费）
   - https://learn.adafruit.com/adafruit-guide-excellent-soldering
2. **SparkFun：如何使用万用表**（免费）
   - https://learn.sparkfun.com/tutorials/how-to-use-a-multimeter

### 重点
- 给笔尖镀锡并保持清洁
- 加热焊点，而不是焊料
- 目测识别冷焊
- 先通孔技术，后表面贴装技术
- 使用助焊剂

### 练习任务
- 将排针焊接到转接板上，用导通模式测试每个引脚，重复三次
- 拆焊其中一个引脚并重新焊接

## 4. Python、终端和 Git

### 学习资源
1. **CS50P：Python编程入门**（哈佛大学，免费）
   - https://cs50.harvard.edu/python/
2. **Python for Everybody**（Coursera，可免费旁听）
   - https://www.coursera.org/specializations/python
3. **你计算机科学教育中缺失的一个学期**（MIT，免费）
   - https://missing.csail.mit.edu/
4. **学习 Git 分支**（免费，交互式）
   - https://learngitbranching.js.org/

### 重点内容
- Python：函数、类、文件I/O、JSON、虚拟环境、pip
- 终端：cd、ls、grep、运行脚本、环境变量、ssh
- Git：初始化、添加、提交、推送、分支、README

### 练习任务
从今天起每个项目放一个 GitHub 仓库，README 包含照片、电路图说明、"哪里出了问题以及如何解决"。

## 第1个月里程碑

到本月底，你应该能够：
- [ ] 阅读电路图并在面包板上搭建出图中所示的电路
- [ ] 插入电阻前先计算阻值是否合适
- [ ] 用万用表查找短路、断路或损坏元件
- [ ] 焊接干净的通孔接头并检查电气性能
- [ ] 编写Python脚本在终端运行并推送到GitHub
- [ ] 大声解释为什么电机失速会导致微控制器复位
