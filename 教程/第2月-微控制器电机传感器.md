# 第2个月：微控制器、电机和传感器，以及你的第一个移动机器人

## 本月目标
制造一个能够移动、感知环境并自我纠正的机器人。

---

## 1. Arduino

### 学习资源
1. **Paul McWhorter，《Arduino课程》**（免费）
   - https://toptechboy.com/arduino-lessons/
   - 超过100节课，循序渐进，每节课后有作业

2. **Arduino 内置示例**（官方、免费）
   - https://docs.arduino.cc/built-in-examples/

3. **Arduino 官方文档，学习部分**（官方、免费）
   - https://docs.arduino.cc/learn/

4. **Arduino 项目中心**（免费）
   - https://projecthub.arduino.cc/

### 重点内容
- digitalWrite/digitalRead/analogRead/analogWrite 及 PWM 含义
- 中断及其必要性
- I2C 和 SPI：连接方式及传感器数据手册查找
- 串口调试
- millis() 而非 delay() 实现非阻塞计时

### 练习任务
制作反应计时游戏：LED随机延迟亮起，按钮停止计时，毫秒级输出到串口。使用中断、消抖、非阻塞计时，带分数功能。

## 第2个月里程碑

到本月底，你应该能够：
- [ ] 以可控速度驱动电机，理解PWM占空比与实际转速的区别
- [ ] 读取编码器并闭合位置环路
- [ ] 无需教程，根据数据手册连接和读取I2C传感器
- [ ] 将加速度计和陀螺仪数据融合为稳定的角度估计
- [ ] 解释P、I、D各自作用，描述改变它们时机器人的反应
- [ ] GitHub展示两个可运行机器人（接线图、代码、故障说明）
