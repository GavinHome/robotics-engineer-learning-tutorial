> 核心：电阻分压、ADC 换算、多次采样平均、单点校准

## 一、目标

把 ESP32-S3 变成一个**能用的直流电压表**。这是第二周的收尾项目，把 Day 8（GPIO）、Day 12（ADC）、Day 13（Serial）串起来。

**关键认知**：ESP32 的 GPIO 只能承受 0~3.3V，直接接 5V 就烧。分压电路不是可选项，是**保护电路**。

---

## 二、分压电路

```
   被测电压 VIN
        │
    ┌───┴───┐
    │ 10kΩ  │  R_HI
    └───┬───┘
        │
        ├────────────── GPIO1 (ADC1_CH0)
        │
    ┌───┴───┐
    │  1kΩ  │  R_LO
    └───┬───┘
        │
       GND
```

### 公式

```
V_PIN = VIN × R_LO / (R_HI + R_LO)          // GPIO1 处电压
VIN   = V_PIN × (R_HI + R_LO) / R_LO        // 反推被测电压（代码里就这句）
```

本电路分压比 = (10+1)/1 = **11**，所以 `VIN = V_PIN × 11`

| V_PIN | VIN |
|-------|-----|
| 0V | 0V |
| 1.65V | 18.15V |
| 3.3V | **36.3V ← 量程上限** |

量程 **0 ~ 36.3V**，覆盖常见的 3.3V / 5V / 12V / 24V。

### 为什么用 10kΩ+1kΩ，而不是指南说的 1MΩ+100kΩ

分压比一样都是 11:1，但**等效源阻抗**差 100 倍：

| 方案 | 等效源阻抗 | 后果 |
|------|-----------|------|
| 1MΩ + 100kΩ | ≈ 91kΩ | ADC 采样电容充不满 → 读数系统性偏低 5~15%，得并一个 104 电容去救 |
| **10kΩ + 1kΩ** | **≈ 909Ω** | 采样充足，读数准，**不需要电容** |

代价：输入阻抗从 1.1MΩ 降到 11kΩ。测电池、测电源轨完全够用；只是测高内阻的信号源（比如某些传感器输出）会把电压拉低一点。对 Day 14 来说这个代价不值一提，换来的是少一个元件、少一个坑。

> 顺带一提：Day 12 用 10kΩ 电位器时没遇到这问题，就是因为它阻抗只有几 kΩ。

## 三、接线（照着插就行）

### 需要的元件

| 元件 | 数量 | 库存 |
|------|------|------|
| 10kΩ 电阻 | 1 | ✅ |
| 1kΩ 电阻 | 1 | ✅（Day 6 用过 1 个，还剩 9 个） |
| 公对母杜邦线 | 3~4 根 | ✅ |
| ESP32-S3 N16R8 | 1 | ✅ |

电阻不分方向，怎么插都行。

### 面包板插法

把两个电阻**串成一排**（首尾相接形成一条链），插在同一列或相邻列上：

```
   [ VIN 输入线 ]           ┌── 10kΩ ──┐── 1kΩ ──┐
                            │          │         │
                            │          │         │
                          VIN       中点        GND
                                      │
                                      └── GPIO1 信号线
```

具体三步：

1. **串两个电阻**：10kΩ 的一脚插面包板第 10 列，另一脚插第 15 列；1kΩ 的一脚也插第 15 列（和 10kΩ 共用一个孔，这就是"中点"），另一脚插第 20 列。
2. **中点 → GPIO1**：一根杜邦线，从**第 15 列**接到 ESP32-S3 的 **GPIO1**。
3. **1kΩ 另一端 → GND**：一根杜邦线，从**第 20 列**接到 ESP32-S3 的 **GND**。
4. **10kΩ 另一端 → 被测电压正极**：一根杜邦线，从第 10 列引出，另一端**先不接**，这是"表笔"。

> 第 10/15/20 列只是举例，任意三列都行，关键是两个电阻要在中间那一列**共用一个孔**。

### 接线顺序（重要）

⚠️ **先接 GND，最后接 VIN**。拆线时反过来，先拆 VIN。
⚠️ **ESP32 要先上电**（插着 USB 线）再接被测电压。板子没上电时 GPIO 内部保护二极管可能把外部电压灌进芯片。

### 上传

1. Arduino IDE 打开 `实验1-数字电压表.ino`
2. 选对开发板和端口，上传
3. 打开**串口监视器**，波特率设 **115200**


然后每秒一行：

```json

```

### 四项验证

| # | 怎么做 | 应该看到 |
|---|--------|---------|
| 1 | **表笔不接任何东西**（悬空） | `vin` 接近 0.00，状态 `LOW`，灯**蓝色** |
| 2 | 表笔接板上的 **3V3** 引脚 | `vin` 接近 3.30，状态 `OK`，灯**绿色** |
| 3 | 表笔接**电位器中间脚**（电位器两侧接 3V3 和 GND） | 旋转电位器，读数在 0~3.3 之间平滑连续变化 |
| — | 表笔接板上的 **5V** 引脚 | ⚠️ 5Vin 输出阻抗高，接分压负载后电压 collapses 到 0，暂不可用 |

第 1 项能过，说明电路接对了（1kΩ 下拉把悬空引脚稳稳拉到地，不会乱飘）。

## 五、校准

### 为什么需要

电阻通常是 ±5% 精度（金环），两个串起来最坏差 10%。这个误差代码修不掉，只能校准。

### 怎么做

1. 万用表量板上 **3V3 引脚**的真实值，记下来，比如 `3.33V`
2. 表笔接 3V3，看串口读数，比如 `3.31V`
3. 算：`CAL_SCALE = 3.33 / 3.31 = 1.0055`
4. 改代码第 45 行 `const float CAL_SCALE = 1.0055;`，重新上传
5. 再测 3V3 验证，读数应接近真实值

> 注：5Vin 引脚输出阻抗高，接 11kΩ 分压负载后电压 collapses 到 0，暂不可用。用 3V3 做校准基准即可。

⚠️ **两个坑，都是实测踩出来的**：

1. **必须用当次的读数算**。原始读数会在不同次测量之间漂移（当天两次测 3V3：3.24V → 3.31V，差 2.2%）。
   拿旧读数算系数会过校正：曾按 3.16V 算出 `1.0538`，上传后读数变成 **3.49V**，
   误差从 −2.7% 放大到 **+4.8%**，比不校准还差。
2. **单点乘性校准修不了零点偏移**。证据：`adc 328` 按理是 `328/4095×3.3 = 0.264V`，
   但 `v_pin` 报 0.302V，差约 38mV（ESP32 ADC 低端非线性）。
   要连偏移一起修得做**两点标定**，把换算改成 `vin = a × vPin + b`，见 [`校准记录.md`](./校准记录.md)。

校准值记在 [`校准记录.md`](./校准记录.md) 里。

### 已经处理掉的误差

| 误差来源 | 量级 | 处理 |
|---------|------|------|
| Vref 不准 | ±5% | ✅ 用 `analogReadMilliVolts()` 读 eFuse 出厂校准值 |
| ADC 噪声 | ±1~2 LSB | ✅ 16 次采样平均 |
| 源阻抗过高 | -5~15% | ✅ 改用 10kΩ+1kΩ，根子上解决 |
| 电阻公差 | ±10% | ⚠️ 靠上面的单点校准 |
| ADC 两端非线性 | 低端/高端 | ⚠️ 避开，代码已标 `LOW` 提示 |

## 六、Python 端读取（可选）

```python
import serial, json

ser = serial.Serial('/dev/cu.usbmodem1101', 115200)   # macOS
# ser = serial.Serial('COM3', 115200)                  # Windows

while True:
    try:
        data = json.loads(ser.readline().decode('utf-8').strip())
        print(f"VIN = {data['vin']:.2f} V  [{data['status']}]")
    except (json.JSONDecodeError, UnicodeDecodeError):
        pass   # 忽略启动时的半截行
```

## 七、出了什么问题 & 怎么修

| 症状 | 原因 | 修复 |
|------|------|------|
| 串口完全没输出 | 波特率不对 / USB 线只供电不传数据 | 设成 115200；换支持数据的 USB 线 |
| 悬空时读数乱飘，不是 0 | 1kΩ 没接到 GND，或两电阻没共用中点 | 检查中点连线、GND 连线 |
| 读数乱跳无规律 | 被测源与 ESP32 没共地 | 补接 GND |
| 读数固定偏差 10% 左右 | 电阻公差 | 做单点校准 |
| 接 5V 读数明显不对（差好几倍） | 两个电阻接反了 | 10kΩ 靠 VIN 侧，1kΩ 靠 GND 侧 |
| 1V 以下读数不准 | ESP32 ADC 低端线性度差 | 正常现象，代码已标 `LOW` |
| 板子发烫 / GPIO 烧了 | 输入超 36V 或接到市电 | 本表无隔离保护，只能预防 |

## 八、与《逐日指南》的出入

| 指南原文 | 本 README | 理由 |
|---------|-----------|------|
| 1MΩ + 100kΩ 分压 | 改成 10kΩ + 1kΩ | 源阻抗从 91kΩ 降到 909Ω，无需去耦电容，精度更好 |
| 采样 10 次 | 16 次 | 折中，约 3ms，对 1s 周期无影响 |
| `raw * 3.3 / 4095.0` | `analogReadMilliVolts()` | 用 eFuse 出厂校准值，精度 ±5% → ±1% |
| 报警 `<1V 或 >3.3V` | 改成 `<1V 或 ≥30V` | 指南的 3.3V 是**引脚**阈值；换算到输入端应是 36.3V 量程 |
| 用真实直流稳压电源验证 | 用板上 3V3/5V + 电位器 | 稳压电源还没买；板上引脚已知电压够做基准 |
| 无状态指示 | 板载灯绿/蓝/红 | Day 14 起彩灯从心跳灯升级为状态指示 |
