### 关于助焊剂芯（今日实测项）

焊锡丝有**空心**和**实心**两种：

- **含助焊剂芯（松香芯）**：丝中间空心灌了松香。焊接时松香自动流到焊点，不用另外蘸。**看到烟、闻到松香味 = 含芯**。
- **实心**：必须先蘸松香再焊，否则焊锡不流动、堆成球、必冷焊。

**今天怎么测**：剪 3cm 锡丝，烙铁头（已镀锡）去化它。冒白烟 + 松香味 + 锡液自动摊开 → 含芯；只化成一个球滚来滚去、不沾铜 → 实心，全程先蘸松香。

> 五件套那条判断不了就按"实心"处理（每次焊前蘸松香），做了总比没做安全。德力西那条到货后是主力。

## 四、第一步：烙铁头镀锡（必做，别跳）

新烙铁头或发黑的旧头，**不镀锡就几乎不导热**，你会误以为是温度不够。

1. 湿海绵擦一遍烙铁头（趁凉）
2. 通电，等 1~2 分钟
3. 锡丝**轻轻碰一下**烙铁头 —— 化了就到温了
4. 把锡丝在头部**整个工作面**抹一圈，让它挂上一层银亮的锡
5. 湿海绵"嚓"一下擦掉多余的，留薄薄一层

**判断标准**：头部呈**均匀银亮色**，不是黑、不是紫、不是斑驳。

> 如果怎么都挂不上锡（锡滚成球掉下去），说明头已经严重氧化：趁热在松香里反复蹭几下再上锡。还不行就得换头。

**用完也要镀锡**：每次收工前重新上一层锡再断电，这层锡是隔绝空气的保护层，能大幅延长烙铁头寿命。

## 五、焊接五步法（今天的全部动作）

```
  ① 加热焊盘和引脚（不是加热锡丝）
        ↓
  ② 送锡到"焊盘与引脚交界处"（不是烙铁头上）
        ↓
  ③ 锡熔化并自己流满焊盘  →  先撤锡丝
        ↓
  ④ 再撤烙铁
        ↓
  ⑤ 别动，等它自然凝固（1~2 秒）
```

### 关键三点（新手 90% 的错都在这）

**① 先加热焊件，不是先化锡。**
烙铁头同时压住**引脚和焊盘**，让两者一起升温。把锡丝直接怼在烙铁头上化，锡是"涂"上去的，不是"焊"上去的 —— 这就是冷焊的头号来源。

**② 锡送在交界处，靠毛细作用吸进去。**
锡会往热的地方跑。烙铁在引脚一侧，锡丝从**对面**送，看到它自己被"吸"满整个焊盘就够了。

**③ 锡要够少。**
一个焊点约**米粒大小**。堆成球 = 锡多了，可能桥连相邻焊盘；缩成一个凹坑 = 锡少了，机械强度不够。

**"怎么算少"的判断标准**（不靠目测，靠三条硬指标）：

| 判断点 | 合格的样子 |
|--------|-----------|
| 时间 | 送锡**不超过 1 秒**就撤 —— 锡是自己被毛细作用吸进去的，不是"堆"上去的 |
| 边界 | 锡的边缘**收在焊盘内**，看得见焊盘外圈的一圈铜色（锡没漫出去） |
| 轮廓 | 是**小丘**不是**球** —— 引脚从丘顶冒出来一小截，丘面向上收口 |

> 若撤锡时感觉"还在往里灌"，说明送多了 —— 下次把送锡时间减半。
> **例外**：焊**多股软导线**时，锡必须吃到包住整股铜丝（会明显比米粒多），这是对的，不算超量。

**时间**：单个焊点 **2~3 秒**。超过 5 秒还没化，说明热没传过去（最常见：烙铁头脏了/没镀锡，或只碰到了引脚没碰到焊盘）。**停下来重新镀锡，别硬怼**。

## 六、练习 1：废电路板上点焊（≥5 个点）

洞洞板在路上，**废弃电路板完全可以替代** —— 目标只是练"送锡量"和"撤锡时机"，跟板子是不是新的无关。

**更省的做法**：把单排针插在废板的孔里焊，这样同时练到 Day 16 要做的通孔焊接。

### 怎么练

1. 找一块废板，选 **5 个不相邻**的孔（别挨着，方便单独看每个焊点）
2. 每个孔插一根排针（或剪段元件脚），板子**翻过来**焊背面
3. 逐个按 §五 五步法焊
4. 焊完**拔一下**排针：合格的焊点纹丝不动

### 自检表（每个点都过一遍）

| 检查项 | 合格 | 不合格 |
|--------|------|--------|
| 形状 | 圆锥形/小丘状，边界收得干净 | 球状堆起 / 尖刺拉丝 |
| 表面 | **光亮**（像镜面） | 暗淡、粗糙、像豆腐渣 |
| 浸润 | 锡铺满整个焊盘，边缘平滑过渡 | 缩成球、堆在一侧、边缘翘起 |
| 用量 | 米粒大小 | 太多（快连到旁边）/ 太少（看得见孔） |
| 牢固 | 拔不动 | 一拔就掉 |

### 三种典型缺陷

| 缺陷 | 长什么样 | 原因 | 怎么修 |
|------|---------|------|--------|
| **冷焊** | 暗淡粗糙、像豆腐渣；或锡球浮着 | 加热不足 / 焊件没动但没到温 / 撤锡后动了 | **重新加热补一点新锡**，别只是把烙铁压上去 |
| **锡桥** | 相邻两个焊盘连起来了 | 锡太多 | 烙铁头擦干净，压在桥上把多余的锡"粘"走 |
| **虚焊** | 看着是亮的，但一拔就掉 / 万用表不通 | 焊件氧化或脏，锡只包住表面没结合 | 吸锡重来（吸锡器在路上；今天可用烙铁加热后甩掉） |

> ⚠️ **虚焊最阴险**：肉眼看着跟好焊点一样，只有万用表或用力拔才暴露。Day 21 跑车半路失灵，八成是它。

### 加分练习：故意焊一个冷焊当"反面教材"

"表面光亮"和"暗淡粗糙"这两项，**光看文字想象不出来，必须见过实物**。所以练好焊点的同时，**故意焊 1 个坏的**：

**怎么做冷焊**：烙铁压上去，**只贴 1 秒就撤**（焊件还没到温），或者送锡后**边凝固边晃导线**。结果是锡浮在表面、呈**灰白颗粒状**，像**豆腐渣**或**霜**。

**为什么要做**：把好的和坏的**并排放在同一张照片里**，一眼就能看出差别。以后修板子时，脑子里的参照物是实物，不是文字。

**拍照要点**：侧光（不要闪光灯），同一角度拍好/坏各一个，对比色差最明显。

- 自检结果：形状 ✅ / 用量 ✅ 大幅收敛 / 浸润 ✅ / 无锡桥 ✅ / 无烫伤 ✅
- 表面光亮、牢固度 **照片读不出** → 由下面 ② ③ 的实测回答

### ② 导通测试的有效性（关键）

**问题**：万用表响，只能证明**两支表笔之间**连通。如果板上这两个孔**原本就有覆铜走线相连**，那"响"跟焊点没关系，测试等于白做。

**有效做法（本次已实证）**：

```
① 焊之前：表笔点这两个孔 → 不响   ← 证明裸板上这两点本就不通
        ↓
② 焊上导线
        ↓
③ 焊之后：表笔再点同一个位置 → 响   ← 此时才证明是"焊点"建立了导通
```

**实测**：

| 步骤 | 结果 |
|------|------|
| ① 裸板这两孔 | **不连通**（不响） |
| ② 焊接后 | **连通**（响） |
| 结论 | ✅ **排除了"板上本就有走线"的干扰，证明焊点本身导通** |

> 📌 这条是本项目的一条通用方法论：**任何"通断测试"都要先问一句"会不会本来就通？"** 没有对照组，"响"不构成证据。Day 16 拆焊、Day 21 整车接线排查都继续沿用。

### ③ 拔线测试（机械强度）

一手按住板子，一手捏住导线，**顺着导线方向**轻拉（绝不向上撬焊盘）。

**实测**：**轻拉不会拉开** ✅ —— 排除虚焊，焊点机械强度合格。

### 验收结论

三项全部通过，**Day 15 达标**。

## 七、练习 2：杜邦线对接焊 + 万用表验证

这是今天唯一有**客观判定标准**的练习。

### 做法

1. 取两根杜邦线，各剥出约 **1cm** 铜芯
2. 铜芯**拧紧成一股**，很重要 —— 散开的铜丝焊完一扯就断
3. **先套热缩管**（如果有的话；没有就最后用电工胶带，或不包，练习用）
4. 给拧好的铜芯**先镀锡**：烙铁压住铜丝，送锡，让它吃进去，变成一根硬的整体
5. 两根镀好锡的线头**并排贴住**，烙铁压住，补一点点锡让它们连成一体
6. 冷却 2 秒后**用力拽**：不脱开才算过

### 你的实测方法（单线两端焊板法）

你用的方法更直接：剪一段 USB 线，两端剥开 → 铜丝拧紧镀锡 → 两头焊在废板两个焊盘上 → 万用表两表笔碰两个焊盘 → **响** = 两头都焊透了，且线本身导通。

这种做法的好处是一次测了两个焊点 + 导线本身，比单焊点测试更严格。

**实测结果**：

- 过程：[`焊接导线测导通.png`](./焊接导线测导通.png)
- 万用表：**响** ✅
- **焊前对照**：这两个孔在裸板上**本来不连通**（表笔点上去不响）→ 焊完才响，说明导通是**焊点建立的**，测试有效 ✅
- **拔线测试**：顺着导线方向轻拉，**不脱开** ✅

### 万用表验证（通用方法）

DT9205A PRO 打到**导通档**（二极管/蜂鸣档，表笔短接会响）：

| 测哪 | 应该 |
|------|------|
| 线的**两端金属** | **响**（导通，蜂鸣） |
| 这根线和**另一根线**（相邻导体） | **不响**（绝缘，说明没锡桥） |

**两项都过** = 焊接合格。响不出来的，回 §六 找原因重焊。

> ⚠️ **测之前先问一句**：这两个点**本来是不是就通的**？如果板上本来就有覆铜走线相连，"响"证明不了任何关于焊点的事。
> 正确顺序：**焊前先量一次（应该不响）→ 焊后再量（响）**，前后对比才构成证据。本次实操已按此流程验证，见 §六·五。

## 九、出了什么问题 & 怎么修

| 症状 | 原因 | 修复 |
|------|------|------|
| 锡不沾，滚成球一直跑 | 烙铁头氧化没镀锡 / 焊件氧化 | 海绵擦 + 松香里蹭 + 重新镀锡；焊件用刀片刮亮 |
| 焊点永远暗淡粗糙 | 温度不够或加热时间太短 | 烙铁头同时压住引脚**和**焊盘，等 1 秒再送锡 |
| 焊点尖刺拉丝（像冰锥） | 撤烙铁太快或太慢 | 锡流满后先撤锡丝、再干脆地撤烙铁，别拖 |
| 焊完一拔就掉 | 虚焊 | 吸锡重来，焊前刮亮焊件 |
| 相邻两点连在一起 | 锡太多 | 烙铁头擦净，压在桥上把锡粘走 |
| 烙铁头越来越黑 | 用完没镀锡 / 海绵太干 | 每次收工前上锡；海绵保持湿润 |
| 松香烟太大看不清 | 正常 | 风扇往外吹，别对着烙铁吹（会降温） |
