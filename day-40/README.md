# Day 40 — 互补滤波：把两种失效焊成一个可信角度

> 硬件：Day 39 不变——MPU-6050 模块 + ESP32-S3，四根杜邦线直连，**不装车**
> 核心：加速度计抖、陀螺仪漂，互补滤波各取所长——角度环要的"不漂移俯仰角"今天落地
> 固件：[`实验1-两种失效.ino`](./实验1-两种失效/实验1-两种失效.ino) ｜ [`实验2-互补滤波.ino`](./实验2-互补滤波/实验2-互补滤波.ino)

Day 39 把 raw 校平了（三个加速度分量 + 三个角速度，都归位）。今天从"三个分量"变成**一个俯仰角**——角度环只认这一个数。当天验收：静止 60 秒漂移 < 1°。

## 一、角度环只认一个数，但单靠谁都不行

俯仰角有两个来源，各带着一种治不好的病：

| 来源 | 算法 | 病 | 好处 |
|---|---|---|---|
| 加速度计 | `atan2(-ax, sqrt(ay²+az²))` | **静止也在抖**——单帧噪声 ±0.02g（Day 39 实时值看到的跳动）≈ ±1° 的角噪声 | 绝对参考，**永不漂** |
| 陀螺仪 | `pitch += gyr_y × dt` 积分 | **零偏积分成单向漂**——Day 39 实测陀螺零偏量级 75 LSB ≈ 0.57°/s，积分 60 秒假走 **34°** | 平滑、响应快 |

一个抖、一个漂，单用任何一个都不行。**融合**是唯一出路：让快的那个管快变，让不漂的那个管慢变。

## 二、实验 1：两种失效各长什么样

先看病，再开药。固件并排打两个角（10Hz）：

```
accel= +0.87  gyro= +0.12  diff= +0.75  t=  5s
accel= +0.91  gyro= +2.34  diff= -1.43  t=  6s
```

- `accel`：围着真值上下抖，**不跑远**——噪声，均值可信
- `gyro`：很平滑，但一个劲地单方向爬——零偏被积分成了漂移
- `diff`：两者的差距，稳定变大，**这就是"必须融合"的实感证据**

流程：烧录 → 看上电打印的标定值（从 Day 39 的 flash 读）→ 板子摆好别扶 → 发 `z` 归零计时 → 盯着看 60 秒。

| 观察项 | 预期 | 实测 |
|---|---|---|
| accel 60 秒抖幅 | 围着真值 ±1° 上下，不跑远 | 均值 +2.77°，std 0.32°（范围 1.46–4.30°），不跑远 |
| gyro 60 秒漂移 | 单向，速率 ≈ 零偏对应的 °/s | 单向 −3.76°（−0.063 °/s），基本线性 |
| diff 走势 | 基本线性变大，方向固定 | 2.4° → 7.4°，方向固定 |

> 板子实测微倾 2.8°（桌面/模块自身不水平）——不影响结论：accel 是绝对参考，围着这个真值抖就是对的；实验2 按 `z` 时以当前角为基准，微倾不会污染统计。

> ⚠️ 上电若打 `⚠️ flash 里没有标度`，说明只跑过 Day 39 实验1、没跑六面标定——先烧 Day 39 实验2 把六面标定跑完再回来，否则 Y 轴差几个百分点（Day 39 实测 4.6%），含 Y 的姿态上 accel 角会偏。

## 三、互补滤波：高通给陀螺，低通给加速度计

```
angle = α × (angle + gyr_y × dt) + (1 − α) × accel_angle
```

- **陀螺项**：`angle + gyr_y×dt` = 上一刻的角度 + 这一刻转了多少。它对**快变**敏感、对慢变（漂移）放任——相当于**高通**。
- **加速度计项**：重力说的真值。它对**慢变**（真实倾角）可信、对快变（噪声）抓瞎——相当于**低通**。
- 两个频段互补，拼起来全频段都有人管；**谁的病另一个都治不了**——这就是"互补"这个名字的来意。

α = 信任陀螺的比例。α=0.98：98% 信积分，2% 信加速度计。它同时决定**校正时间常数**——加速度计把融合角拉回真值的快慢：

```
τ = α × dt / (1 − α)        （dt = 0.01s，100Hz）
```

| α | τ | 含义 |
|---|---|---|
| 0.90 | 0.09s | 拽得紧：噪声压得狠，但真实倾角也被拽得迟钝 |
| 0.95 | 0.19s | |
| 0.98 | 0.49s | 平衡车的常用区间 |
| 0.995 | 1.99s | 放任漂：要陀螺零偏很小才敢用 |

**一个可以提前算出来的数：静止时融合角的稳态偏差 ≈ 陀螺漂移速率 × τ。** 实验1 实测本次板子的残余零偏只有 **−0.063 °/s ≈ −8 LSB**，比 Day 39 记的 75 LSB 小一个量级——六面标定顺带用 48 秒静止把陀螺零偏重测了一遍，比 Day 39 那次更准。按实测值推算：

| α | τ | 推算稳态偏差 | 能不能过 1° 验收 |
|---|---|---|---|
| 0.90 | 0.09s | 0.006° | 轻松 |
| 0.95 | 0.19s | 0.012° | 轻松 |
| 0.98 | 0.49s | 0.031° | 轻松 |
| 0.995 | 1.99s | 0.125° | 轻松 |

**所以四档在静止这一关全都过得去，漂移已经分不出高下。** 真正把它们区别开的是另外两项：抬手 30° 的跟上时间（≈ τ，0.09s 和 1.99s 手感差 20 倍）和手持微抖（低通压不干净说明 α 选小了）。验收不是走形式，只是考的不是漂移。

## 四、实验 2：α 四档一次调完

固件并排打三个角，一眼看出滤波的疗效：

```
accel= +0.91  gyro= +2.34  fused= +0.95  a=0.980  maxDev=0.12  t= 12s
```

- `accel`：还是那个抖（病没变）
- `gyro积分`：还是那个漂（病没变）
- `fused`：**又稳又不漂**——两个病都被治了

键位：`1`/`2`/`3`/`4` 切 α（0.90 / 0.95 / 0.98 / 0.995）；`z` 置零并开始验收；`v` 打印完整状态块（可整段复制）。

**每档流程**：按数字键切档 → 按 `z` → **手离开板子**，等 3 秒取稳 → 静止 60 秒（看 `maxDev` 和到点的结论行）→ 抬手约 30° 停住，看 `fused` 多久跟上（≈ τ）。

| α | τ | 静止 60s 最大偏离 | 30° 抬手跟上时间 | 观感 |
|---|---|---|---|---|
| 0.90 | 0.09s | 1.59° | | |
| 0.95 | 0.19s | **0.56°（达标）** | | |
| 0.98 | 0.49s | 1.83° | | |
| 0.995 | 1.99s | 2.40° | | |

**这几行的 maxDev 不能横向比高下**——污染来自测试台，不是 α 的差异：按 `z` 时板子还没落稳（基准记下运动中的值，实测那一刻融合角与加速度计差 0.78°），加上杜邦线张力在慢慢拉板子（一段里 accel 单调爬 1.95°）。真正环境干净的那段（α=0.95，accel 60 秒只漂 0.10°）拿到 0.56° 达标，证明链路、标定、滤波都没问题。

四档共同的有效结论：**`fused` 全程紧跟 `accel`（差 ≤0.05°），而 `gyro积分` 单独在漂**——互补滤波确实把两个病都治了，这一条四档独立成立，不依赖横向比较。

> `z` 之后**先等 3 秒再取基准**：刚摆好、或刚抬手放下就按 `z`，板子还在动，记下的基准是运动中的值——实测踩过，按 `z` 那一刻融合角和加速度计能差 0.78°，前两秒 accel 自己冲 1.5°，`maxDev` 全被这段污染。基准取的是稳下来的那个角，不是 0，板子微倾也没关系。

## 五、验收：三种姿态静止 60 秒，最大偏离 < 1°

指南原话：三种姿态（平放 / 微倾 / 手持微抖）各静止 60 秒，最大偏离 < 1°。

| 姿态 | 怎么摆 | 60s 最大偏离 | 判定 |
|---|---|---|---|
| 平放 | 桌面，松手 | | |
| 微倾 | 一端垫个东西（约 5-10°） | | |
| 手持微抖 | 手捏着，故意轻微抖 | | |

**这项没做，原因记在这里**：桌面裸板 + 松线这个测试台，环境振动和线张力就能造出 1~2° 的假偏离（实测陀螺换算出的角速度波动 20 °/s，而 1° 门限要求参考自己稳在 1° 以内），1° 这个门限在这种台面上测不了。等装车（Day 44）用刚性机架重做，那时 α 也才真正作数——见 §九。

**为什么要三个姿态**：平放专治漂移（低 α 也能过）；微倾验零偏和标度（倾斜时 ax 真正参与，标度错立刻现形）；**手持微抖专治"太信任加速度计"的档位**——手抖是高频，低通本该压掉它，压不干净说明 α 选小了。

## 六、验收不过查什么

按这个顺序查，别乱调：

**第 0 步：先看 `accel` 稳不稳。** 60 秒里 accel 自己跑超过 0.5°，是环境在震/板子没静止，不是 α 的问题——这轮作废重测。判据：accel 是绝对参考，它自己动的时候，`maxDev` 测到的是板子的动、不是滤波的错。

**怎么区分"板子在动"和"数据坏了"**：看 `gyro积分` 列，两个传感器测的是同一个运动。真振动时两者帧间波动同步——实测 corr(Δaccel, Δgyro积分) = +0.5，且陀螺换算出的角速度波动（15~23 °/s）和 accel 的摆动幅度（±1.5°）对得上；I2C 总线被干扰时两个传感器各坏各的、不相关。实测踩过：打字震动着桌面，四档 accel 帧间 std 0.66~0.90°（安静时只有 0.32°），四档全"未达标"，但 `fused` 紧咬 `accel`（差 ≈0.0°）——滤波没毛病。

**最有效的一招：按完 `z` 人就离开桌子**，默数 60 秒再回来按下一档（手机计时）。20 °/s 的角速度波动手是感觉不到的，打字、笔记本风扇、桌面共振都到这个量级。

1. **零偏脏了** → 回 Day 39 重按 `k`，或重跑一遍六面标定。零偏错，accel 角整体偏，fused 会被慢拽到一个错的角度上——而且**错得很稳，看不出来**。
2. **`dt` 写死了** → 必须是实测差值（本固件用 `micros()`）。写死 0.01，loop 一抖动积分就走样，静止时 `gyro积分` 会无规则地抖。
3. **α 选错** → 大：漂（稳态偏差 ≈ 漂速 × τ，见 §三的表）；小：抖 + 抬手迟滞（手持微抖那关过不去）。
4. **陀螺符号反了** → 症状明确：**倾斜时 `fused` 远离 `accel` 而不是跟随**（一个往上一个往下）。把 `GYR_SIGN` 改成 `-1` 重烧。
5. **标度没加载** → 上电打了 `⚠️ flash 里没有标度`。没跑六面标定，Y 轴差几个百分点，含 Y 的姿态 accel 角偏。
6. **线松了 / MPU 被震** → raw 全 0 或跳变，先按 Day 39 的办法查线，别的都白搭。

## 八、几个今天就会遇到的坑

**`dt` 必须是实测差值，且精度要够。** 100Hz 采样，`millis()` 的 1ms 分辨率相当于 ±10% 的 dt 量化误差——积分 60 秒，这些误差累加出来就是 `gyro积分` 的无规则抖动。用 `micros()`，精度高一个量级。

**`micros()` 会溢出，但无符号减法不怕。** 它每约 71.6 分钟回零一次，`now - last` 用无符号减法自动处理回绕，只要 dt 存 `float` 就没事。存成 `int` 或 `unsigned long` 再当毫秒用，才会在回绕那一帧炸出个巨大的 dt。

**符号今天不用管，只管"跟不跟"。** 倾斜时 `fused` 跟着 `accel` 同向走，融合就是对的；至于"往前倾算正还是算负"，取决于 MPU 在模块上的贴片方向，装车时（Day 44）再统一——那时要配小车的"前进"方向。

**别拿竖着的板子做验收。** 加速度计角 `atan2(-ax, sqrt(ay²+az²))` 在板子接近竖立时（`az→0`）分母趋零，噪声被放大成角度乱跳。平衡车只在竖直附近 ±10° 工作，那个区间恰好是最灵敏最好用的区域——竖放是退化区，不是考验。

**低通已经开了。** `REG_CONFIG = 0x03`（≈44Hz）和 Day 39 一致，单帧噪声已压过一轮。今天不换量程；哪天换了，Day 39 的校准要重跑——标度是绑死量程的。

**坏数据长什么样，认得出比调参重要。** 实测踩过两个叠在一起的坑：

- **标定值是垃圾**：上电打印里三个标度**全是 16384**，或有零偏到上万 LSB。16384 是六面标定守卫的兜底值——六个姿势的 `(max−min)` 全 ≤ 1000 LSB，说明标定时板子根本没换姿势，零偏记下的是那一个姿势的读数。此时 accel 角整体偏一个固定值，而且**偏得很稳，看不出来**。
- **I2C 中途断了**：动板子把杜邦线带松，raw 变成全 0。症状极其好认：accel 角**冻在一个数上纹丝不动**，gyro 以**恒定速率**单向爬——实测那两个数（−6.19°、−1.646°/s）正好等于 `raw=0` 经过去偏后的算术结果，不是测量值。固件现在会丢这种帧并每秒警告一次，丢帧不积分、不打印。

先看打印再动手调 α——数据源坏了，四档 α 全白测。

## 九、还欠的

- ⏳ **装车后的 α 才作数**。桌面静止和车上振动不是一回事：电机高频振动会全喂给加速度计（低通那端），α 可能要往大调。Day 44 角度环接上 `fused` 和 `gyr` 时再定。§四 的四档 maxDev 已在桌面测过但不可横向比较（测试台污染），§五 三种姿态验收也未做——两项都留到装车后用刚性机架补。
- ⏳ **Kalman 滤波**（指南挪进阶）。互补滤波是"够用"的解：权重固定。Kalman 是同思想的更优解：权重按两个传感器的噪声协方差自适应——噪声大时自动少信它。原理先记住"都是加权融合"，公式以后补。
