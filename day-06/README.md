# Day 6：点亮 LED — 剪线取电直供方案

> 日期：2026-09-07
> 状态：✅ 电路已点亮，待万用表补充测量数据

---

## 实验概述

原计划使用 MB102 电源模块为面包板供电，但模块绿灯不亮、无输出。改用 USB 剪线取电方案，直接给面包板供电并点亮 LED。

**供电方式**：剪断废旧 USB 充电线，取红(+5V)/黑(GND)线芯，直接接入面包板电源轨。

---

## 电路拓扑

```
电源（充电头 5V）
    │ USB-A 方头
    ▼
红线 ──→ 面包板 + 轨
黑线 ──→ 面包板 − 轨

+ 轨 ── 1kΩ 电阻 ── LED 长脚（阳极）
LED 短脚（阴极） ── 按钮 ── − 轨
```

**供电后直接点亮 LED**，按钮为瞬动型，按住亮、松开灭。

## 遇到的问题

### 1. MB102 电源模块绿灯不亮

**现象**：USB 供电后按下白色按键，绿色电源 LED 不亮，面包板无输出。

**排查过程**：
1. 换过多根 USB 线 + 多个电源（充电宝、充电头）
2. 用手机测试同一根线能正常充电 → 线和电源正常
3. 确认充电宝 Type-C 口可能不向"傻设备"放电，但充电头 USB-A 口也无效

**结论**：模块本身故障（USB 座虚焊或内部断路），待万用表终审后找商家补发。

**解决**：改用 USB 剪线取电，零成本绕过 MB102。

### 2. 按钮实现"按一下保持亮，再按灭"

**现状**：瞬动按钮只能按住亮、松开灭。

**方案**（未实施，待后续学习）：
- 短期：换自锁型轻触按键（按下去咔哒卡住）
- 中期：ESP32 代码检测按键翻转（见下方代码片段）
- 长期：用 PN2222 搭双稳态触发器（Day 10+ 数字电路）

## 代码片段（ESP32 替代方案）

如果后续用 ESP32 Core S3 替换按钮，实现单键翻转：

```cpp
const int btnPin = 0;    // 按钮接 GPIO0，另一端接 GND
const int ledPin = 2;    // LED 串电阻后接 GPIO2
bool ledOn = false;
bool lastBtn = HIGH;

void setup() {
  pinMode(btnPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
  digitalWrite(ledPin, LOW);
}

void loop() {
  bool curBtn = digitalRead(btnPin);
  if (lastBtn == HIGH && curBtn == LOW) {
    delay(20);
    if (digitalRead(btnPin) == LOW) {
      ledOn = !ledOn;
      digitalWrite(ledPin, ledOn ? HIGH : LOW);
      while(digitalRead(btnPin) == LOW);
    }
  }
  lastBtn = curBtn;
}
```

## 经验总结

1. **充电宝 Type-C 口不一定对无协议设备供电**，插墙充电头更可靠
2. **USB 剪线取电是最快的面包板供电方案**，无需购买电源模块
3. **先接线、后通电**，避免裸线短路烧电源
4. **瞬动按钮 vs 自锁开关**：前者靠手指维持，后者靠机械记忆——根据场景选择
